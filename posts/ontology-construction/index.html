사용자와 기존 문제

제조·반도체·배터리 자료가 파일마다 다른 용어와 링크로 쌓여 관련 원문과 최근 변경문서를 다시 찾기 어려웠습니다.

문서가 검색후보가 되는 흐름

flowchart LR A["Markdown·YAML 원문"] --> B["변경파일 확인"] --> C["검색단위·Metadata"] --> D["ChromaDB 동기화"] Q["자연어 질문"] --> E["Embedding"] --> D --> F["후보문서"] --> G["Reranking"] --> H["제목·원문 확인"]

내가 직접 구성한 범위

  • 산업별 Markdown 문서와 Metadata 규칙
  • 문서링크를 이용한 관계 인덱스
  • 변경된 문서만 다시 처리하는 동기화 흐름
  • 자연어 질문의 후보검색·재정렬 CLI
  • 검색결과에서 제목과 원문을 다시 확인하는 연결

현재 확인한 범위

현재 확인한 결과는 Markdown 원본관리, 변경분 동기화와 후보검색·재정렬입니다. 생성 인덱스 재구축의 반복시험, 검색결과의 원문위치 화면, 운영보안·권한, 자동 품질판정은 완료 결과가 아닙니다. 검색결과만으로 품질·안전판단을 승인하지 않습니다.
