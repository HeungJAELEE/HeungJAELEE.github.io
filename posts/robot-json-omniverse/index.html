Project SOW — 공개 기준 업무범위

목적: QR 제품 시리얼을 공통 키로 사용해 로봇 조립, Vision 판정, PLC·SCADA 상태와 MySQL 이력을 연결합니다.

성공 기준: 식별 → 조립 → 검사 → 분기 → 적재/통과 → 기록이 하나의 실물 시연으로 이어지고, 팀 결과와 개인 기여가 구분되어야 합니다.
