면접 답변 기준

가장 어려웠던 점

한 대의 로봇 좌표를 만드는 것보다 QR 시리얼, 로봇 완료 상태, Vision 판정과 DB 기록이 같은 제품을 가리키게 만드는 일이 더 어려웠습니다. 전체 공정과 인터페이스를 먼저 정의하고 팀별 구현을 그 기준에 연결했습니다.

직접 구현 범위

전체 프로젝트 기획과 Indy7 로봇 제어·연동이 주 범위였습니다. Vision 모델, PLC Ladder와 SCADA 상세 구현은 담당 팀원이 수행했고, 보고서와 최종 발표는 팀장이 담당했습니다.

Vision 수치를 생산 성능으로 쓸 수 있는가

사용하지 않습니다. 교육 데이터와 특정 평가 조건의 결과이며 실제 불량 대표성, 독립 Test set, Confusion Matrix와 현장 검증이 필요합니다.

“QR 제품 추적, 세 대의 Indy7 조립공정, Vision 검사와 DB·SCADA를 하나의 공장 시퀀스로 기획했습니다. 저는 로봇 제어와 공정 간 연동을 직접 맡았고, 전체 시연은 10인 팀 결과입니다.”
이 페이지는 원 발표자료, 확인된 역할 경계와 후속 공개 코드 범위를 분리해 작성했습니다.
