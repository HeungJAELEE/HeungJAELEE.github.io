프로젝트 배경과 Vision

PLC의 설비상태, SCADA의 관제정보와 SQLite의 생산이력이 서로 다른 기준으로 관리되면 생산기술 엔지니어가 병목구간이나 증설 시나리오를 같은 데이터 기준에서 비교하기 어렵습니다.

이 프로젝트는 3D 가상화 화면을 만드는 데서 끝내지 않고, 가상공정 Event→PLC State→OPC UA Tag→SCADA·SQLite 이력→AI 의사결정 보조 도구 Advisory가 하나의 의미체계로 이어지는 생산기술 지원 플랫폼을 설계하는 것을 목표로 했습니다.

저는 10인 팀의 전체 기획과 통합 구성을 맡았습니다. 공정상태를 AI가 읽을 수 있는 구조로 정리하되, 최종 판단은 생산기술 엔지니어가 소유하는 의사결정 보조 도구 원칙을 프로젝트의 설계 기준으로 두었습니다.

공정 가상화와 상태전이

GIGA Press 흐름을 Factory I/O에서 구현 가능한 원자재 투입–CNC 가공–불량검사–Tray 이송–Stacker 적재·배출 시나리오로 추상화했습니다.

flowchart LR A["원자재 투입"] --> B["CNC 가공"] B --> C{"불량검사"} C -->|NG| D["불량 배출"] C -->|GOOD| E["Tray 이송"] E --> F["Stacker 적재"] F --> G["Stacker 배출"]

각 공정은 설비명 목록이 아니라 다음 Step으로 넘어가기 위한 상태전이로 정의했습니다. Material Ready, Machining Complete, 검사판정, Tray 도착과 Rack 적재완료가 PLC·Factory I/O·SCADA에서 같은 Event를 가리키도록 정렬했습니다.

Tag·상태 정합성 Mapping

OPC UA 구간의 설계 기준을 Tag 이름, Data Type, 상태 의미와 Timestamp로 두고, 분과별 화면과 이력이 같은 공정 Event를 가리키도록 Mapping했습니다. 통신 연결 자체보다 상태의 의미가 하위 제어에서 상위 분석까지 유지되는지를 통합 기준으로 삼았습니다.

AI 의사결정 보조 도구 Interface

제어와 분석 분리

핵심 구성 원칙은 PLC 제어 영역과 AI 분석 영역을 분리하는 것입니다.

물리적 제어와 안전기능은 PLC의 Sequence·Interlock에 고정했습니다. 의사결정 보조 도구는 OPC UA와 SQLite의 상태·이력만 읽기 전용으로 사용하며, PLC로 직접 명령을 되돌리는 경로를 두지 않았습니다. 이를 통해 AI 분석을 추가해도 기존 제어권한과 안전책임이 흔들리지 않도록 경계를 설계했습니다.

엔지니어 최종 승인

엔지니어 승인 원칙에 따라 DQN·분석모델의 출력은 설비 명령이 아니라 엔지니어가 검토할 분석 결과로 정의했습니다.

Factory I/O Layout, 상세 Ladder, SCADA/OPC UA 화면과 Web 구현은 각 담당 팀원이 수행했습니다. 저는 이 결과가 서로 다른 기능의 집합으로 남지 않도록 같은 공정상태·같은 데이터 의미·같은 사용자 판단 흐름으로 묶는 통합 아키텍트 역할을 맡았습니다.

정상 흐름 통합 시연

Factory I/O·PLC 공정제어

Start·Reset·Stop·E-Stop 입력, PLC Step과 Factory I/O 동작을 같은 흐름에서 확인했습니다. 상세 Ladder 작성은 PLC 팀이 담당했습니다.

SCADA·SQLite 상태와 이력

Rack 위치, Stacker 적재상태와 Alarm을 SCADA와 가상공정에서 같은 기준으로 비교하고, SCADA에서 SQLite로 이어지는 Event·생산이력 흐름을 연결했습니다.

Web 생산지표 View

Web UI는 설비상태와 생산정보를 한 화면에서 검토하도록 구성했습니다. 의사결정 보조 도구의 병목·투입·Buffer 검토 제안도 같은 생산기술 사용자 흐름에 배치하도록 설계했습니다.

기능별 PLC 구조 제안

Emit, Machine, Move, Stacker, Vision 단위의 기능 분리를 제안해 공정변경과 확장 시나리오를 모듈별로 검토할 수 있도록 했습니다. 상세 구현은 PLC 팀 범위입니다.

의사결정 보조 도구·DQN 연계 설계

DQN·분석모델 연계구간은 OPC UA·SQLite 이후에 배치했습니다. Rack·Stacker·Cycle·Buffer·생산량을 분석입력으로 사용하고, 출력은 생산기술 검토 제안으로 제한해 PLC 설비명령과 분리했습니다.
