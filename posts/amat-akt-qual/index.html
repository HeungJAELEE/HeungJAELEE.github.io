현장 문제와 결과 요약

현장 문제
사내 공정 결과가 안정적이어도 고객 측정방법과 기준이 다르면 Qual에서 같은 결과로 인정받기 어려웠습니다.
내가 맡은 일
표면처리·Hi-Pot·내산성·내식성 검사조건을 재구성하고 동일 Sample Correlation과 기술실사 대응을 맡았습니다.
확인한 결과
기술 Qual을 수행했지만 고난도 부품 중심 거래구조와 수익성 문제로 약 1년 뒤 회사 차원에서 거래가 종료됐습니다.

왜 중요한 문제였는가

반도체·디스플레이 장비 부품은 사내 검사에서 합격해도 고객의 측정기, 검사 위치와 판정기준이 다르면 같은 결과로 인정받지 못할 수 있습니다. 실제로 서로 다른 측정기에서 Arc Count와 Ramp Time 결과가 다르게 나타나는 문제가 있었습니다. 특히 표면처리, 절연 성능, 내산성·내식성과 같은 항목은 공정조건과 검사방법을 함께 맞춰야 Qual 결과를 양산에서 반복할 수 있습니다.

초기 상태와 측정기준

처음부터 공정조건만 바꾸지 않았습니다. 사내 측정값과 고객 측정값이 왜 다른지 모르는 상태에서 Recipe를 조정하면, 실제 공정 차이와 측정 차이를 구분할 수 없기 때문입니다.

확인 대상을 세 층으로 나눴습니다.

  1. 공정: 전처리, 표면처리, 세정과 후처리 조건
  2. 제품: 막두께, 조도, 외관, 절연과 내환경 성능
  3. 측정: 장비, Sample 위치, 반복횟수, 판정방법과 Bias

Qual 불일치를 나눈 4M 분석

고객과 측정값이 다르다는 이유로 생산 Recipe를 바로 바꾸면 공정과 측정의 원인이 섞입니다. 4M으로 불일치 가능성을 나누고 동일 Sample 시험의 순서를 정했습니다.

4M확인한 문제확인 방향
Man측정자별 Sample 위치·판독과 고객 요구 해석이 다를 수 있었음측정 위치, 반복횟수와 판정방법을 문서로 맞춤
Machine사내·고객 측정기의 Ramp Time·Arc Count 결과와 반복성이 달랐음동일 Sample 반복측정으로 장비 간 Bias와 반복성 확인
MaterialSample별 소재·표면상태·피막과 전처리 차이가 측정기 차이처럼 보일 수 있었음같은 Sample과 같은 전처리 상태로 비교
Method영문 Spec 해석, 전처리, 검사순서와 판정기준이 공정조건과 따로 관리됐음요구조건·공정조건·검사항목을 한 표로 연결

이렇게 나누면 Machine의 측정 차이를 Method인 Recipe 문제로 잘못 처리하지 않을 수 있습니다. 공정 변경은 측정방법과 Sample 차이를 먼저 정리한 뒤 진행했습니다.

DMAIC로 진행한 Qual

  1. Define — 글로벌 장비업체 요구조건과 사내 공정·검사결과가 같은 기준으로 설명되지 않는 문제를 Qual 범위로 정했습니다.
  2. Measure — 동일 Sample의 막두께·조도·내전압·Arc Count·Ramp Time 등을 반복 측정하고 위치·횟수·Bias를 기록했습니다.
  3. Analyze — 차이를 4M으로 나눠 실제 공정변동, Sample 차이와 측정기·검사방법의 영향을 구분했습니다.
  4. Improve — Bead Blast·Oxalic Anodizing 조건과 검사방법을 고객 Spec에 맞추고 보완항목을 Sample로 다시 확인했습니다.
  5. Control — Qual에서 확정한 조건을 Recipe·Run Sheet·공정표준서와 검사기준에 반영해 양산에서도 같은 방법을 쓰게 했습니다.

직접 수행한 조치

공정과 검사 항목을 같은 표로 맞췄습니다

고객의 영문 Spec을 분석하고 Bead Blast와 Oxalic Anodizing 조건을 검사항목에 연결했습니다. 막두께·조도·색차·내전압, Arc Count, Ramp Time과 Particle·치수 항목을 제품 특성에 맞춰 정리하고, 확인되지 않은 항목은 Sample 검증 대상으로 남겼습니다.

동일 Sample로 측정 차이를 확인했습니다

사내와 고객이 서로 다른 Sample을 측정하면 제품 차이와 장비 차이가 섞입니다. 동일 Sample을 반복 측정해 장비 간 Bias와 반복성을 확인하고, 검사 위치와 전처리 방법도 맞췄습니다. 공정능력과 측정시스템의 신뢰성은 별개의 질문으로 관리했습니다.

기술실사와 보완조치를 추적했습니다

Sample 결과만 제출하는 데서 끝내지 않고, 고객 기술실사에서 확인된 보완사항을 공정·검사·문서 항목으로 나눠 담당자와 재확인했습니다. 변경한 조건은 다시 Sample로 확인한 뒤 표준문서에 반영했습니다.

확인·재시험

  1. 고객 요구조건을 공정조건과 검사항목으로 나눴습니다.
  2. 동일 Sample을 반복 측정해 측정 Bias와 공정 차이를 구분했습니다.
  3. Sample 검증과 기술실사 보완사항을 같은 기준으로 다시 확인했습니다.
  4. Qual에서 확정한 조건을 Recipe·Run Sheet·검사기준에 반영했습니다.

재시험에서는 조건과 검사방법을 동시에 여러 개 바꾸지 않았습니다. 변경 이유, 대상 Sample, 검사 위치와 판정기준을 남겨 다음 결과를 이전 결과와 비교할 수 있게 했습니다.

결과

기술 결과

CVD·PECVD 공정부품의 표면처리와 Hi-Pot·내산성·내식성 기준을 글로벌 장비업체 요구조건에 맞춰 재구성하고 Qual을 수행했습니다. 확인된 조건은 Recipe, Run Sheet, 공정표준서와 검사기준으로 정리했습니다.

사업 결과

기술 Qual과 사업의 지속 여부는 같은 결과가 아닙니다. 이후 고난도 부품 중심의 거래구조와 수익성 문제로 회사가 약 1년 뒤 거래를 종료했습니다. 기술 결과와 회사의 사업 판단은 별도로 정리했습니다.

이 경험에서 남긴 기준

  • 고객과 측정값이 다르면 공정부터 고치지 말고 동일 Sample과 측정방법을 먼저 확인합니다.
  • Qual 승인조건은 개발자 개인 기록이 아니라 현장 Recipe와 검사기준으로 남깁니다.
  • 기술 승인, 양산 적용과 사업 수익성은 서로 다른 결과로 평가합니다.
