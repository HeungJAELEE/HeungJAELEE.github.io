기술 Qual 완료

글로벌 디스플레이 장비사 CVD·PECVD 부품 공정 재구성 및 기술 Qual 획득

Etching·Bead Blast·수산 Anodizing·Hi-Pot 조건을 고객 CTQ로 재구성하고 7회 측정·3회 재시험으로 기술실사 지적 조치 완료

프로젝트 기간
2017.12–2018.12
맥락
와이엠씨 기술연구소 재직 중 수행
담당 범위
영문 Spec·CTQ, Process Flow·Run Sheet, 공정변경, 대응 Sample·계측, 외부분석, 기술실사·재시험 조치 완료

프로젝트 핵심 요약

과제 정의
기존 공정·검사조건과 글로벌 장비사 제품군별 Spec·Hi-Pot 판정기준 Gap
핵심 역할
영문 Spec→Process Flow·Run Sheet 전환, 공정별 5M·Hi-Pot Correlation 주도
주요 결과
7회 반복·3회 재시험 기반 기술실사 지적 1건 조치 완료, 기술 Qual·약 1년 후속 납품

항목 내용
기간 2017.12–2018.12
대상 글로벌 장비사 CVD·PECVD용 Susceptor·Diffuser 계열 부품
공정 범위 Etching→Bead Blast→수산계 Anodizing→물성·Hi-Pot·Particle
직접 역할 영문 Spec·CTQ 분석, 공정변경 설계, Process Flow·Run Sheet·Qual 자료 주작성, 대응 Sample·계측·기술실사·재시험
완료 결과 기술실사 지적 1건 조치 완료·기술 Qual 승인·약 1년간 후속 납품

1. 기존 공정 Gap

공정·관리축 기존 상태 고객 요구와의 Gap
Etching·전처리 공정순서·검사시점 분산관리 영문 Spec·제출자료와 항목 불일치
Bead Blast 제품군 공통조건·평가기록 표면조도·Particle 요구 미연계
수산계 Anodizing 사내 피막 Setting 중심 두께·Hi-Pot·내산·내식 CTQ 미연계
물성·Particle 개별 시험결과 관리 Process Flow·Sample 이력 연결 부족
Hi-Pot 장비·위치·반복·Ramp·Sequence 차이 사내·고객 판정 불일치
변경점 문서 공정·검사·제출자료 별도 Revision 문서–현장–Sample 일치성 부족

Measure Run Sheet·장비 Capability·Sample·측정조건 기준화 기존조건–고객요구 Gap List

Verify 고객 위치·7회 반복측정·동일 Sequence·3회 재시험 기술실사 지적사항 1건 조치 완료
Control 공정·검사·Sample·문서 Revision 동기화 기술 Qual·후속 생산기준 이관

3. 공정별 변경점과 5M

공정 핵심 원인 변경 전 문제 변경한 내용 검증
Etching·전처리 Man·Method·Measurement 작업순서·검사시점·Sample 이력 분리 Process Flow·Run Sheet Sequence 재정렬 피막두께·조도·외관·후공정 대조
Bead Blast Machine·Method·Measurement 제품군별 표면요구 미반영 조건·평가항목·Anodizing 투입기준 재구성 조도·외관·Particle 비교
수산계 Anodizing Material·Machine·Method 사내 Setting·고객 CTQ 불일치 제품군별 피막조건·검사 Spec 재설계 두께·Hi-Pot·내산·내식
Hi-Pot Machine·Method·Measurement 장비·위치·반복수·Ramp·Arc 판독차 고객 위치·7회·승압·Sequence·Arc 기준 정렬 보완 Sample 3회 재시험
내산·내식·Particle Method·Measurement 사내결과–고객 Capability 연결 부족 시험조건·검사 Spec·외부분석 Correlation 사내·외부·고객자료 대조
변경점 관리 Man·Method 공정·검사·제출자료 Revision 불일치 공정–검사–Sample–문서 동시개정 기술실사 문서·현장 일치검증

4. Hi-Pot 측정 Correlation

동일 Bath·동일 제조조건 대응 Sample
→ 고객 지정 측정위치
→ Sample당 7회 반복측정
→ 사내·고객 장비차이 비교
→ Ramp Time·승압·시험 Sequence 정렬
→ Arc Counter 판독기준 통일
→ 보완 Sample 제작
→ 동일 판정원칙 3회 재시험
→ 기술실사 지적 1건 Closure

공정 Recipe를 바꾸기 전에 측정 장비, 위치, 반복 횟수, 측정 순서를 고객 기준에 맞췄습니다. 이후 보완 Sample 재시험으로 사내 검사 결과와 고객 판정이 일치하는지 확인했습니다.

추가·개정한 위험항목 예방·검출 Control 표준문서 추가·개정

Hi-Pot 판정 Correlation 실패 위치·7회·Ramp·Sequence·Arc 통일 측정 Sequence·결과보고서
외부분석–사내결과 단절 Sample ID·시험조건·결과 연결 Qual 자료·Sample 결과표
