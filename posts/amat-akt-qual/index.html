제조 프로젝트

기술 Qual 완료

글로벌 디스플레이 장비사 CVD·PECVD 부품 공정 재구성 및 기술 Qual 획득

Six Sigma GB 기반 DMAIC와 공정별 4M+Measurement로 Bead Blast·수산 Anodizing·Hi-Pot 조건을 재구성해 실사 지적 1건을 Closure

프로젝트 기간
2017.12–2018.12
맥락
와이엠씨 기술연구소 재직 중 수행
담당 범위
영문 Spec·공정별 4M+Measurement, Bead Blast·수산 Anodizing·검사조건 재구성, 대응 Sample·계측, 기술실사와 재시험 Closure

프로젝트 핵심 요약

과제 정의
기존 사내 공정·검사조건과 글로벌 장비사 요구가 일치하지 않았고, 동일 Bath·제조조건의 대응 Sample도 Hi-Pot 판정이 달랐습니다.
핵심 역할
영문 Spec을 공정별 변경점으로 분해하고 Bead Blast·수산 Anodizing·검사조건을 재구성했으며, Hi-Pot 측정 Correlation과 기술실사 재시험을 담당했습니다.
주요 결과
고객 지정위치·7회 반복·승압·시험 Sequence·Arc 판독을 정렬하고 3회 재시험으로 지적 1건을 Closure해 기술 Qual과 약 1년 후속 납품으로 연결했습니다.

프로젝트 개요

  • 기간: 2017.12–2018.12
  • 대상: 글로벌 디스플레이 장비사의 CVD·PECVD용 Susceptor·Diffuser 계열 부품
  • 공정 범위: Etching → Bead Blast → 수산계 Anodizing → 물성·Hi-Pot·Particle 검사
  • 직접 역할: 영문 Spec 분석, 공정별 변경점 도출, Process Flow·Run Sheet·Qual 자료 주작성, 대응 Sample 제작·계측, 외부분석, 기술실사와 재시험 Closure
  • 결과: 기술실사 지적 1건 Closure, 기술 Qual 승인, 승인 부품 약 1년 후속 납품

기존 공정에서 무엇이 문제였는가

기존 사내 공정은 Etching, Bead Blast, Anodizing과 검사설비를 보유하고 있었지만, 글로벌 장비사의 제품군별 요구조건을 기준으로 공정조건·Run Sheet·검사기준이 하나의 흐름으로 정리된 상태는 아니었습니다.

  • Etching부터 Anodizing까지 실제 작업순서와 고객 영문 Spec의 항목이 일대일로 연결되지 않음
  • Bead Blast·수산 Anodizing 조건이 제품군별 표면·피막 요구와 분리되어 관리됨
  • 피막두께·조도·내산·내식·Particle 결과가 Process Flow와 Sample 이력에 일관되게 연결되지 않음
  • 동일 Bath·동일 제조조건의 대응 Sample도 사내와 고객의 Hi-Pot 장비·측정위치·반복횟수·승압·시험 Sequence·Arc 판독 차이로 판정이 달라짐

따라서 공정 Recipe만 조정해서는 실제 피막문제와 측정체계 차이를 구분할 수 없었습니다. 고객 요구를 CTQ와 공정별 변경점으로 다시 나누고, 공정조건과 검사조건을 각각 재구성한 뒤 동일 기준으로 재시험하는 순서가 필요했습니다.

Six Sigma GB 기반 DMAIC 적용 순서

단계확인한 문제직접 수행결과·산출물
Define신규 공급사 등록에 필요한 공정 Capability와 고객 CTQ가 불명확영문 Spec·제출자료·대상부품·합격항목 목록화공정범위, CTQ, 기술실사 대응항목 정의
Measure기존 사내 Setting과 고객 요구조건의 차이를 한 기준으로 비교하기 어려움공정별 Run Sheet, 장비 Capability, Sample 결과와 측정조건 기준선 확인기존조건–고객요구 Gap 목록
Analyze공정불량과 측정조건 차이가 혼재Etching·Bead Blast·Anodizing·Hi-Pot을 4M+Measurement로 분리변경할 공정조건과 유지·정렬할 측정조건 구분
Improve제품군별 공정조건과 검사 Spec이 고객 요구에 맞지 않음Bead Blast·수산 Anodizing 조건 재구성, 시험조건·검사 Spec 갱신Process Flow·Run Sheet·Recipe·검사기준 개정
Verify사내·고객 Hi-Pot 판정 불일치대응 Sample, 고객 지정위치, 7회 반복, 동일 Sequence, 3회 재시험기술실사 지적 1건 Closure
Control문서와 실제 현장조건이 다시 달라질 위험SOP·QCP·Run Sheet·변경점·Sample 결과 연결기술 Qual 승인과 후속 납품 기준 이관

공정별 변경점과 4M+Measurement

공정·관리축기존 문제핵심 원인축변경한 내용재검증
Etching·전처리실제 작업순서와 고객 Spec·제출자료의 관리항목이 분리Man · Method · Measurement공정순서, 관리항목, 검사시점과 Sample 이력을 Process Flow·Run Sheet로 재정렬피막두께·조도·외관과 후속공정 결과 대조
Bead Blast제품군별 표면 요구와 기존 공통조건·기록방식이 맞지 않음Machine · Method · Measurement제품군별 Bead Blast 조건과 평가항목을 재구성하고 Anodizing 투입조건과 연결조도·외관·Particle 결과 비교
수산계 Anodizing기존 사내 Setting과 고객 피막·내전압·내산·내식 요구가 불일치Material · Machine · Method제품군별 Anodizing 공정조건과 Recipe를 재구성하고 검사 Spec 갱신피막두께·Hi-Pot·내산·내식성 확인
Hi-Pot 검사사내·고객 장비, 위치, 반복수, Ramp Time, Sequence와 Arc 판독 차이로 판정 불일치Machine · Method · Measurement고객 지정위치, Sample당 7회, 승압·시험 Sequence와 Arc Counter 판독기준 정렬보완 Sample 3회 재시험, 지적 1건 Closure
내산·내식·Particle사내 결과만으로 고객 요구 Capability를 설명하기 어려움Method · Measurement시험조건·검사 Spec을 갱신하고 필요한 항목은 외부기관 분석과 Correlation사내·외부 결과와 고객 제출자료 대조
변경점 관리공정변경, 검사변경과 제출문서가 서로 다른 버전으로 남을 위험Man · MethodProcess Flow, Run Sheet, SOP, QCP, 검사기준과 Sample 결과보고서를 같은 변경점으로 관리기술실사에서 문서–현장–Sample 일치 여부 확인

프로젝트 공통 4M+Measurement 판단

원인축기존 문제판단근거변경·관리
Man작업자·문서작성자·검사자별 공정순서와 판정 해석 차이실제 작업, Run Sheet와 Sample 기록 대조작업순서·측정순서·기록항목 통일
Machine공정장비 Capability와 사내·고객 Hi-Pot 장비·Arc 판독 차이장비 보유현황, 반복측정과 고객 결과 비교장비별 역할을 명확히 하고 Hi-Pot 조건 Correlation
MaterialSusceptor·Diffuser 제품군과 별도 대응 Sample의 형상·피막 요구 차이동일 Bath·동일 제조조건 대응 Sample 비교제품군별 조건을 분리하고 Sample 이력 고정
Method기존 내부 Setting·시험 Sequence와 고객 요구조건 불일치고객 Spec, Run Sheet, 재시험 결과 대조Bead Blast·수산 Anodizing·시험조건 재구성
Measurement측정위치·7회 반복·승압·Arc Counter 판독이 통일되지 않음같은 조건 대응 Sample의 사내·고객 판정 차이고객 기준으로 측정·판정원칙 정렬 후 3회 확인실험

1. Etching·Bead Blast 공정 재구성

Etching은 실제 전처리 순서와 관리항목을 고객 Spec·Sample 결과에 맞춰 다시 연결하는 작업이 핵심이었습니다.

  • Etching 작업순서와 관리항목을 Process Flow·Run Sheet에 재배치
  • 처리 후 표면상태를 조도·외관과 연결
  • Bead Blast 투입 전후의 Sample 이력과 검사시점 고정
  • 고객 제출자료와 실제 생산기록의 항목명·순서 정렬

Bead Blast는 제품군별 표면 요구를 반영해 조건과 평가항목을 재구성했습니다.

  • 제품군별 Bead Blast 조건 분리
  • 조도·외관·Particle을 공정결과로 연결
  • 후속 Anodizing 피막결과와 함께 비교
  • 선정조건을 Run Sheet와 검사기준에 반영

2. 수산계 Anodizing 조건과 검사 Spec 변경

기존 사내 Setting을 그대로 사용하는 대신 CVD·PECVD 부품군의 피막 요구에 맞춰 Anodizing 공정조건을 재구성했습니다.

  • 제품군별 수산계 Anodizing 조건·Recipe 재정리
  • 피막두께와 표면상태 관리항목 연결
  • Hi-Pot·내산·내식성 시험조건과 검사 Spec 갱신
  • 조건별 대응 Sample 제작과 사내 직접측정
  • 필요한 항목은 외부기관 분석과 사내결과 Correlation

공정조건 변경은 피막두께 하나만 만족시키는 방식이 아니라, Hi-Pot·내산·내식·Particle 결과가 함께 고객 요구를 만족하는지를 기준으로 선정했습니다.

3. Hi-Pot 측정시스템 Correlation

기술실사의 핵심 지적은 동일 제조조건 대응 Sample의 내전압 판정이 사내와 고객에서 다르게 나온 문제였습니다.

기존 측정 차이

  • 사내·고객 측정장비 차이
  • 고객 지정 측정위치와 사내 위치 차이
  • Sample당 반복횟수 차이
  • Ramp Time과 시험 Sequence 차이
  • Arc Counter 판독기준 차이

변경·재시험

  • 고객 지정 위치로 측정점 통일
  • Sample당 7회 반복측정 적용
  • 승압조건·시험 Sequence 정렬
  • Arc Counter 판독원칙 통일
  • 동일 Bath·동일 제조조건의 보완 대응 Sample 제작
  • 동일 판정원칙으로 3회 재시험

이 순서로 공정불량과 측정조건 차이를 분리했고, 원인분석·보완조치·재시험 결과를 제출해 기술실사 지적사항 1건을 Closure했습니다.

4. 기술실사 Closure와 Control

기술실사에서는 다음 항목을 문서와 실제 현장 기준으로 대조했습니다.

  • 보유 장비와 측정원리
  • Etching·Bead Blast·Anodizing Process와 Run Sheet
  • 변경점 관리와 Sample Traceability
  • 피막두께·조도·Hi-Pot·내산·내식·Particle 결과
  • 외부기관 분석과 사내결과 Correlation
  • 지적사항 담당·조치·재시험·종료조건

표준화 산출물

  • Process Flow·Run Sheet
  • 제품군별 Bead Blast·수산 Anodizing 공정조건
  • SOP·QCP·검사기준
  • Hi-Pot 측정·판정 Sequence
  • 영문 Qual 자료와 Sample 결과보고서
  • 기술실사 지적사항 조치·재시험 보고서
  • 변경점 관리와 후속 Sample 대응기준

최종 성과

  • 기존 사내 공정과 고객 요구의 Gap을 공정별 4M+Measurement로 분리

  • Hi-Pot·내산·내식 시험조건과 검사 Spec 갱신
