배경

제이스텍 재직 당시 NCM Pilot Line에서는 극판, 조립, 검사와 Formation 등 공정별 MES 데이터가 각각 기록되고 있었습니다. 문제는 양극·음극·분리막과 두 개의 J/R이 하나의 Cell로 합쳐진 뒤, 그 관계를 한 번에 조회할 방법이 없었다는 점이었습니다. 같은 Lot 안에서도 자재 조합이 달라질 수 있었고, 극판 재작업까지 발생하면 생산일만으로는 정확한 이력을 추적하기 어려웠습니다.

극판 생산부터 조립과 Formation까지의 공정 Lead Time은 약 3주였습니다. 고객이 특정 Cell S/N의 이력을 요청하면 앞뒤 생산일 자료를 일일이 대조해야 했고, 보통 10개 Cell의 제조조건과 검사결과를 정리하는 데 약 3일이 소요됐습니다.

접근

Cell 단위 조회 기능을 MES에 추가해 달라고 요청했지만 비용 문제로 진행되지 않았습니다. 그래서 기존 공정 기록 사이의 연결관계를 별도 도구에서 정의하는 방식으로 접근했습니다.

조회 기준은 Cell S/N으로 정했습니다. 하나의 S/N에서 양극, 음극, 분리막, Tape, Can, Cap Ass’y와 전해액 등 구성자재를 찾고, 다시 극판 Roll의 생산위치와 조립·검사 결과, Formation 용량까지 이어지도록 조회 순서를 설계했습니다.

데이터와 시스템 흐름

flowchart LR A["공정별 MES·Excel
극판·조립·검사·Formation"] --> B["Power Query
파일 수집·열 구조 정리"] B --> C["Cell S/N 연결표
자재·J/R·공정 관계"] C --> D["Excel VBA 조회
S/N 입력·연속 검색"] D --> E["생산이력 결과
Roll 위치·검사·용량"] E --> F["현장 확인
이상 패턴과 원인 후보"]

구현

  • Power Query: 공정별 MES·Excel 파일을 취합하고 열 구조를 정리했습니다.
  • Cell S/N 연결표: 자재, J/R과 공정 사이의 관계를 정의했습니다.
  • Excel VBA: S/N을 입력하면 극판 Roll부터 Formation까지 연속으로 검색하도록 조회 버튼과 연결 로직을 만들었습니다.

약 3주 동안 업무 후 시간을 활용해 직접 제작했습니다. 현장에서 반복하던 검색 순서를 하나씩 확인하고, 그 순서를 코드와 조회양식으로 옮겼습니다.

결과

도구 적용 후 단일 Cell 이력은 약 5~10초 안에 조회할 수 있었습니다. 10개 Cell의 전체 조사시간도 약 3일에서 약 3분으로 줄었습니다. 3일을 72시간으로 환산한 경과시간 기준으로는 약 99.9% 단축된 결과입니다.

조회 결과를 해석하고 고객용 보고서로 정리하는 작업에는 별도로 반나절 정도가 필요했습니다. 검색시간과 보고서 작성시간은 성격이 다른 업무이므로 각각 구분해 관리했습니다.

활용: 용량 이상 Cell 역추적

생산 Cell에 이상이 발생하면 구성자재와 공정조건, 검사결과를 다시 확인해야 합니다. 이 도구를 용량 이상 Cell에 적용해 S/N별 이력을 비교한 결과, 여러 Cell이 같은 극판 Roll의 특정 생산구간을 거쳤다는 공통점을 확인했습니다.

점검범위를 해당 극판공정으로 좁혀 설비상태를 확인했고, Pump의 미세진동으로 체결부가 풀리면서 코팅량이 달라진 사례를 찾았습니다. 이력 조회가 공정원인을 대신 판단한 것은 아니지만, 수작업 파일 대조에 쓰이던 시간을 줄여 실제 Roll 구간과 설비를 확인하는 데 집중할 수 있었습니다.

운영과 한계

재직 당시 실제 생산이력 조회에 사용했고, 담당자가 같은 방식으로 검색할 수 있도록 사용순서와 파일 갱신방법을 인계했습니다.

Excel과 Power Query 기반이므로 원본 파일의 열 이름이나 저장 형식이 바뀌면 연결조건도 함께 수정해야 합니다. 원본 데이터가 누락된 경우에는 해당 공정의 기록을 먼저 보완한 뒤 다시 조회하도록 운영했습니다.

이 도구가 필요했던 생산 배경과 공정 인수 과정은 NCM 각형 Pilot Line 인수와 초기 안정화 사례에서 확인할 수 있습니다.
