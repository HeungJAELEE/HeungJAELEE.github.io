현장 문제와 사용자

공정별 MES가 없어서 생긴 문제가 아니었습니다. 극판, 조립, 검사와 Formation 기록은 각각 남아 있었지만, 한 Cell을 기준으로 전체 이력을 이어서 볼 수 없었습니다.

조립공정에서는 양극·음극·분리막과 두 개의 J/R이 하나의 Cell로 결합됩니다. 같은 생산 Lot 안에서도 실제 자재 조합이 달라질 수 있고, 극판 재작업이 있으면 생산일만으로 원본과 후속 이력을 맞추기 어려웠습니다. 극판 생산 약 1주와 조립·Formation 약 2주를 합쳐, 특정 Cell을 확인할 때는 앞뒤 약 3주의 자료를 대조했습니다.

주요 사용자는 Pilot 생산·기술 담당자와 고객 Sample 이력보고 작성자였습니다. 고객이 무작위로 지정한 10개 Cell의 제조조건과 검사결과를 검색하고 정리하는 데 약 3일이 필요했습니다.

Cell 단위 조회기능을 기존 MES에 추가해 달라고 요청했지만 비용 문제로 진행되지 않았습니다. 직접 수행한 범위는 현장 검색순서 분석, 데이터 연결항목 정의, Power Query 취합, Excel VBA 검색·연결 로직, 원본자료 대조와 담당자 인계까지입니다.

데이터 연결 논리

  1. Cell S/N을 조회 시작점으로 사용했습니다. 생산일만으로 찾지 않고 해당 S/N의 조립 레코드에서 J/R과 구성자재 키를 확인했습니다.
  2. 조립키를 자재와 극판 기록으로 역추적했습니다. 양극·음극·분리막과 부품 Lot를 찾고, J/R에 연결된 극판 Roll과 생산구간까지 이동했습니다.
  3. 자재변경과 재작업을 덮어쓰지 않았습니다. 같은 Cell에 여러 레코드가 연결되면 공정시각과 작업구분을 기준으로 원본과 후속이력을 함께 표시했습니다.
  4. 다음 공정의 키를 이어서 검색했습니다. 조립·검사·Formation까지 같은 Cell의 흐름으로 연결했습니다.
  5. 조회결과는 원본자료와 다시 맞췄습니다. 자동으로 연결됐다는 이유만으로 완료하지 않고 공정별 원본 MES·파일과 S/N·Lot·시각을 대조했습니다.

Material/Data · Method · Measurement

Cell 성능과 제조이력을 연결해 확인구간 축소

도구가 원인을 자동판정한 것이 아니라, 공통 Roll·생산구간을 찾아 현장점검 대상을 좁혔습니다.

현상과 판정기준

용량이 나오지 않는 Cell이 반복됐지만 단위공정 화면만으로는 공통원인을 찾기 어려웠습니다. 성공기준은 이상 Cell의 S/N에서 실제 자재·J/R·극판 Roll과 생산구간을 연결하고, 원본기록과 현장점검으로 같은 원인을 확인하는 것이었습니다.

원인축확인한 후보판단근거판정조치
Man수작업 검색순서와 담당자 경험같은 이상 Cell도 확인파일과 순서가 달랐음조사시간 변동요인, 제품원인 아님조회순서를 고정하고 원인판정과 분리
Machine / System단위 MES 연결부재와 극판 Pump 상태S/N 비교 후 같은 Roll 구간으로 범위가 좁혀짐연결부재는 조사병목, Pump는 현장 원인후보공통 Roll 구간과 Pump 상태를 우선 점검
Material / Data공통 극판 Roll·생산구간여러 이상 Cell에서 같은 구간이 반복핵심 추적근거같은 Roll 구간을 우선 확인
MethodS/N별 이력비교 후 공통구간 현장점검파일 전체가 아니라 공통구간을 우선 확인핵심 분석방법공통구간 중심으로 현장점검
MeasurementFormation 용량, S/N·Lot·시각, 코팅량과 원본기록성능과 제조구간을 같은 Cell 흐름으로 연결최종 판정근거조회결과와 원본기록 교차확인
Environment공정환경반복패턴과 직접 연결되는 근거 없음주요 원인에서 제외기존 환경조건을 유지하고 공정근거에 집중

조치·재시험

조회결과에서 여러 Cell이 같은 극판 Roll의 특정 생산구간을 거쳤다는 공통점을 찾았습니다. 해당 설비를 점검해 Pump의 미세진동과 체결부 풀림으로 코팅량이 부족해진 구간을 확인했습니다. 도구는 원인을 자동판정하지 않고, 확인해야 할 Roll 구간과 설비를 좁히는 역할을 했습니다.

표준화

이상 Cell 조사 시 S/N→J/R→자재·극판 Roll→조립·검사→Formation 순서로 확인하고, 자동 연결결과는 원본기록과 다시 대조하도록 조회·보고 절차에 반영했습니다.
