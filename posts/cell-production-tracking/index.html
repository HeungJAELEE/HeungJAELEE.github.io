프로젝트 배경과 목표

NCM Pilot Line에는 극판·조립·검사·Formation 공정별 MES와 Excel 기록이 존재했지만, 특정 Cell 한 개의 전체 제조이력을 연속 조회하는 기능은 없었습니다.

고객이 무작위로 지정한 Cell S/N의 제조조건을 확인하려면 극판 생산 약 1주, 조립·Formation 약 2주를 합친 앞뒤 약 3주의 파일을 열어 수작업으로 대조해야 했습니다. 10개 Cell의 자재·공정·검사이력을 찾고 보고서로 정리하는 데 약 3일이 소요됐습니다.

현장 PC에서 바로 사용할 수 있도록 기존 공정기록을 변경하지 않고, Cell S/N 하나로 극판 Roll부터 Formation까지 이어지는 생산이력 추적 자동화 도구를 직접 설계·개발했습니다.

Data 처리 흐름 — 공정파일 통합과 Key Mapping

공정별 MES·Excel 파일
→ Power Query 열구조 정규화·Refresh
→ Cell S/N 기준 조립 Record 조회
→ J/R·자재 Lot 추출
→ 극판 Roll·생산구간·재작업 이력 연결
→ 조립·검사·Formation 결과 연결
→ VBA 결과표·보고서

1. 데이터 취합

  • 공정별 파일의 열 이름·형식·저장위치 정리
  • Power Query 기반 파일 취합과 Refresh 순서 구성
  • Cell·자재·공정·검사·Formation 조회용 Table 생성
  • 파일 갱신 후 동일 구조로 재조회 가능한 운영방식 확립

2. 관계 Key Mapping

연결 단계조회 Key연결 결과
CellCell S/N·조립시각조사대상·조립 Record 식별
조립J/R·부품 Lot실제 Cell 구성자재 확인
극판Roll·Lot·생산구간코팅·압연·절단구간 역추적
변경이력공정시각·작업구분원본·재작업·후속 Record 구분
검사설비·검사결과공정 이상구간 비교
Formation용량·최종 전기결과제조이력과 Cell 성능 연결

Cell S/N을 조회 시작 Key로 사용하고, 조립 Record에서 J/R과 자재 Lot를 추출했습니다. 이후 극판 Roll과 생산구간, 조립·검사·Formation의 다음 Key를 순서대로 연결했습니다.

재작업이나 자재변경으로 여러 Record가 존재하는 경우에는 공정시각과 작업구분으로 원본과 후속 이력을 분리해 표시했습니다.

VBA Application — 일괄검색과 결과표 생성

작업자가 Cell S/N 목록을 입력하고 검색버튼을 누르면 Power Query Table의 관계 Key를 따라 전 공정 이력을 조회하도록 VBA 로직을 구현했습니다.

기능구현 내용
입력Cell S/N 1건 또는 10건 일괄입력
검색조립 Record에서 J/R·자재 Key 추출
역추적극판 Roll·Lot·생산구간·재작업 이력 연결
후공정조립·검사·Formation 결과 연속 조회
결과표Cell별 자재·공정·검사·용량 이력 표시
정합성 검증자동 조회값과 원본 S/N·Lot·공정시각 대조

조회결과는 실제 공정별 원본기록과 S/N·Lot·시각을 교차확인해 연결 정확도를 검증했습니다. 검색과 원인판정을 분리해, 결과표는 공통 Roll·Lot·공정구간을 빠르게 좁히는 조사도구로 사용했습니다.

직접 설계·구현 범위

  • 10개 Cell 이력조사의 기존 작업순서 분석
  • 공정별 데이터 항목과 연결 Key 설계
  • Power Query 파일취합·열구조·Refresh 구성
  • Excel VBA S/N 일괄검색·다음 공정 연결·결과표 구현
  • 재작업·자재변경 Record 구분
  • 자동 조회결과와 원본자료 정합성 검증
  • 사용자 검색절차·파일 갱신·보고서 작성방법 현장 인계

현장 Use Case — 용량 이상 Cell 역추적

상황

용량 미달 Cell이 반복됐지만 단위공정 화면만으로는 공통 제조구간을 찾기 어려웠습니다.

추적

이상 Cell의 S/N을 일괄입력해 약 3분 만에 조립·검사·Formation 이력과 극판 Roll을 역추적했습니다. 여러 Cell이 동일 극판 Roll의 특정 코팅구간을 거쳤다는 공통점을 도출했습니다.

현장 확인

공통구간의 설비를 집중 점검해 Pump 미세진동과 체결부 풀림에 따른 코팅량 부족을 Root Cause로 규명했습니다. 전체 3주 자료를 다시 뒤지는 대신, 조회도구가 지정한 Roll·공정구간을 우선 점검하는 방식으로 원인조사 시간을 전환했습니다.

이상 Cell S/N 일괄입력
→ 공통 J/R·극판 Roll 구간 식별
→ 해당 코팅설비 집중점검
→ Pump 미세진동·체결부 풀림
→ 코팅량 부족 구간 규명

핵심 성과

성과결과
직접 개발기간약 3주
Cell 1건 검색약 5–10초
10개 Cell 검색약 3분
이력조사·보고서 완료약 3일 → 반나절
적용단계현장 적용·담당자 인계

검색 자체와 보고서 전체 업무를 구분했습니다. 10개 Cell의 생산이력 조회는 약 3분으로 단축됐고, 결과해석·표 정리·고객 이력보고서 작성까지 포함한 전체 업무는 약 반나절로 줄었습니다.

표준화·현장 인계

  • 공정별 파일 저장위치·열구조·Refresh 순서
  • Cell S/N 입력과 일괄검색 방법
  • S/N·J/R·Lot·공정시각 연결 Key 확인방법
  • 재작업·자재변경 Record 판독순서
  • 자동 조회값과 원본자료 대조절차
  • 고객 이력보고서에 사용할 조회항목·결과표 작성방법
