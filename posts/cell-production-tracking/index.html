제조 DX 프로젝트

현장 적용·인계

공정별로 끊긴 데이터를 Cell S/N으로 연결한 생산이력 추적 도구

Power Query와 Excel VBA로 극판 Roll부터 Formation까지 제조·검사이력을 한 번에 조회

프로젝트 기간
제이스텍 재직 중 약 3주간 별도 제작
맥락
NCM Pilot Line의 공정별 MES 데이터를 연결하기 위해 직접 제작
담당 범위
데이터 연결항목 정의, Power Query 취합, VBA S/N 검색, 현장 적용과 인수인계

사용자·구현·검증 요약

사용자 문제
공정별 MES는 있었지만 한 Cell의 전체 이력이 연결되지 않아 고객 요청 10개 Cell을 조사하는 데 약 3일이 필요했습니다.
구현 범위
MES 개선 요청이 비용 문제로 반려된 뒤 Power Query 취합과 Excel VBA 검색·연결 로직을 약 3주간 직접 만들었습니다.
결과·현재 단계
단일 검색은 5–10초, 10개 Cell 전체 조사는 약 3분으로 줄였고 재직 당시 현장에 적용해 담당자에게 인계했습니다.
단일 Cell 검색 5–10초
10개 Cell 전체 조사 약 3일 → 약 3분

공정별 MES가 있어도 한 Cell의 이력을 찾기 어려웠습니다

각 공정의 MES는 정상적으로 기록되고 있었습니다. 문제는 양극·음극·분리막과 두 개의 J/R이 한 Cell에 합쳐진 뒤 그 관계를 한 번에 조회할 수 없다는 점이었습니다. 같은 Lot 안에서도 자재 조합이 달라질 수 있었고, 극판 재작업까지 생기면 생산일만으로는 정확한 이력을 찾기 어려웠습니다.

극판 생산부터 조립과 Formation까지 약 3주가 걸렸기 때문에 고객이 Cell S/N을 지정하면 앞뒤 생산일의 데이터를 다시 대조해야 했습니다. 보통 10개 Cell의 제조조건과 검사결과를 정리하는 데 약 3일이 필요했습니다.

Cell S/N을 중심으로 제조·검사 데이터를 다시 연결했습니다

조회 기준을 Cell S/N으로 정하고 필요한 정보를 역으로 연결했습니다. 자재는 양극, 음극, 분리막, Tape, Can, Cap Ass’y와 전해액까지 포함했습니다. 여기에 극판 Roll의 생산위치, 조립·검사 결과와 Formation 용량을 붙였습니다.

중요한 것은 데이터를 새로 만드는 일이 아니라 이미 각 공정에 있던 기록 사이의 연결관계를 정하는 일이었습니다. 특정 S/N을 입력하면 구성자재와 생산구간, 공정결과가 같은 흐름으로 이어지도록 조회 순서를 설계했습니다.

MES 개조 대신 현장에서 쓸 수 있는 조회 도구를 만들었습니다

Cell 단위 조회 기능을 MES에 추가해 달라고 요청했지만 비용 문제로 진행되지 않았습니다. 그래서 Power Query로 공정별 파일을 모으고, Excel VBA로 S/N 검색 버튼과 연결 로직을 만들었습니다.

약 3주 동안 업무 후 시간을 따로 사용해 직접 제작했습니다. 당시에는 AI 도구를 사용하지 않았으며, 현장에서 반복하던 검색 순서를 하나씩 확인해 코드와 조회양식으로 옮겼습니다. 이 작업은 MES를 새로 구축한 것이 아니라 기존 공정 데이터를 Cell S/N 기준으로 연결한 별도 조회 도구입니다.

검색과 보고에 걸리는 시간을 나눠 줄였습니다

개선 전의 약 3일은 10개 Cell을 대상으로 약 3주 분량의 공정자료를 찾아 연결하는 조사시간이었습니다. 도구 적용 후 단일 Cell 검색은 약 5–10초, 보통 10개 Cell의 전체 조사는 약 3분 안에 끝났습니다.

조회 결과를 해석하고 고객용 보고서로 정리하는 작업은 별도로 반나절 정도가 필요했습니다. 검색시간과 보고서 작성시간은 서로 다른 작업이므로 하나의 수치로 합치지 않았습니다.

용량 이상 Cell을 극판 코팅구간까지 역추적했습니다

도구는 단순 조회뿐 아니라 원인 후보를 찾는 데도 사용했습니다. 생산 Cell에서 용량 저하 패턴이 나타났을 때 S/N별 구성자재와 공정이력을 연결하고, 극판 Roll의 생산구간까지 거슬러 올라갔습니다.

같은 구간에서 패턴이 반복되는 것을 확인한 뒤 극판공정을 점검했습니다. Pump의 미세진동으로 체결부가 풀리면서 코팅량이 달라진 사례를 찾았습니다. 도구가 원인을 자동으로 판정한 것은 아니며, 흩어진 기록을 빠르게 모아 현장 확인 범위를 줄여준 사례입니다.

현장에 적용하고 담당자에게 인계했습니다

재직 당시 실제 생산이력 조회에 사용했고, 담당자가 같은 방식으로 검색할 수 있도록 사용순서와 파일 갱신방법을 인계했습니다. Excel과 Power Query 기반이므로 데이터 형식이 바뀌면 연결조건을 함께 수정해야 하는 한계가 있습니다.

이 도구가 필요했던 생산 배경과 공정 인수 과정은 NCM 각형 Pilot Line 인수와 초기 안정화 사례에서 확인할 수 있습니다.
