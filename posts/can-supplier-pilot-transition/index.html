Pilot 공급 전환

대체 Can 공급사 Pilot 전환

기존품과 후보품의 소재·형상 차이를 공정위험으로 바꾸고 3개 Lot의 품질·안전성을 확인한 공급 전환 사례

프로젝트 기간
금양 재직 중 검증 · 2025.03 Pilot 공급 전환
맥락
금양 전지기술팀 · 원통형 Cell 핵심부품 대체공급사 검증
담당 범위
변경점 검토, 조립공정 조건 재설정, 3개 Lot 공정성·품질·안전성 시험, 공정기준과 승인자료 정리

현장 문제와 결과 요약

현장 문제
기존 공급사의 생산능력만으로 후속 생산 수요를 맞추기 어려워 신규 Can 공급사의 제조·품질 적합성을 확인해야 했습니다.
내가 맡은 일
소재 물성과 바닥 형상 차이가 Beading·Crimping·밀봉에 미치는 영향을 나누고 조립공정 조건과 검증 순서를 직접 정했습니다.
확인한 결과
600 Cell·3개 Lot와 공식 UN38.3 시험을 통과한 뒤 기존재고 소진 시점부터 Pilot 후속 생산분과 구매를 대체 Can으로 전환했습니다.
검증 범위 600 Cell · 3개 Lot
안전성 확인 공식 UN38.3 통과

왜 대체 공급사가 필요했는가

기존 공급사의 생산능력만으로 후속 생산수요를 맞추기 어려워 후보 Can의 제조·품질 적합성을 검증했습니다. 공급사 선정이나 단가협상이 아니라 소재·형상 차이가 조립공정과 Cell 안전성에 미치는 영향을 확인하는 업무였습니다.

변경점과 검증

변경점공정위험확인방법판정·반영
합금성분·물성Beading·Crimping 형상과 밀봉 영향성적서·치수·외관 비교Cell 공정과 안전시험까지 추적
바닥부 두께·공차총고·내경·기밀·Vent 영향기존품·후보품 비교Knife·가압량·높이 재설정
단품검사 한계단품 합격만으로 Cell 안전성 판단 불가절단·해체·후속공정·안전시험입고→조립→안전 Gate 구성
검사·승인부서별 판정역할이 다름동일 도면·성적서·치수 기준책임과 최종승인을 별도 관리

직접 수행과 재시험

후보 Can은 단품검사만으로 판단하지 않고 조립조건과 Cell 안전성까지 같은 시험흐름으로 확인했습니다. Beading Knife의 높이·깊이·압력과 Crimping·Sizing의 가압량·높이를 다시 맞춘 뒤, Lot당 200 Cell씩 3개 Lot, 총 600 Cell을 제작했습니다.

정량 검증범위값의미
Lot당 제작수량200 Cell같은 조건의 Lot별 재현 확인
완료 Lot3/3 Lot계획 Lot 기준 100% 수행
총 제작수량600 Cell조립·기밀·후공정·안전시험 범위

총고·내경·외관·기밀·용접부를 비교하고, 용접부 절단·Cell 해체·낙하·Vent 파단압·상하부 압축과 공식 UN38.3 시험으로 최종 적용범위를 확인했습니다.

역할과 승인 경계

구분담당
공정기술변경위험, 조건설정, Sample 제작·평가와 기준작성
품질입고·출하품질 판정
전지기술소재차이에 따른 Cell 성능 검토
구매공급사·발주와 구매전환
최종 승인관련 책임자 공동 검토

결과와 현재 범위

공식 UN38.3 시험을 통과한 뒤 기존재고 소진 시점부터 Pilot 후속 생산분과 구매를 대체 Can으로 전환했습니다. 회사 자금사정으로 상업 양산은 가동되지 않아 실제 절감액과 장기 대량생산 결과는 확인하지 않았습니다.
