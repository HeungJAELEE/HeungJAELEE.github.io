Pilot 공급 전환

대체 Can 공급사 Pilot 전환

기존품과 후보품의 소재·형상 차이를 공정위험으로 바꾸고 3개 Lot의 품질·안전성을 확인한 공급 전환 사례

프로젝트 기간
금양 재직 중 검증 · 2025.03 Pilot 공급 전환
맥락
금양 전지기술팀 · 원통형 Cell 핵심부품 대체공급사 검증
담당 범위
변경점 검토, 조립공정 조건 재설정, 3개 Lot 공정성·품질·안전성 시험, 공정기준과 승인자료 정리

현장 문제와 결과 요약

현장 문제
기존 공급사의 생산능력만으로 후속 생산 수요를 맞추기 어려워 신규 Can 공급사의 제조·품질 적합성을 확인해야 했습니다.
내가 맡은 일
소재 물성과 바닥 형상 차이가 Beading·Crimping·밀봉에 미치는 영향을 나누고 조립공정 조건과 검증 순서를 직접 정했습니다.
확인한 결과
600 Cell·3개 Lot와 공식 UN38.3 시험을 통과한 뒤 기존재고 소진 시점부터 Pilot 후속 생산분과 구매를 대체 Can으로 전환했습니다.
검증 범위 600 Cell · 3개 Lot
안전성 확인 공식 UN38.3 통과

검증 흐름

기존 공급사의 생산능력만으로 후속 생산 수요를 맞추기 어려워 대체 Can 공급사의 공정·품질 적합성을 검증했습니다. 공급사 선정이나 단가협상이 아니라, 소재 물성과 형상 차이가 조립공정과 Cell 안전성에 미치는 영향을 확인하고 Pilot 공급 전환 기준을 만드는 업무를 맡았습니다.

01

4M 기반 부품변경 검증

소재·형상 차이를 조립조건으로 전환

부품 차이와 설비 Setting을 분리해 Beading·Crimping/Sizing 조건을 다시 맞췄습니다.

변경점

  • 후보 Can은 기존품과 합금성분 비율, 바닥부 두께와 일부 공차가 달랐습니다.
  • 같은 도면군이라도 소재의 탄성·경도 차이가 Beading과 밀봉 형상에 영향을 줄 수 있었습니다.
  • 기존 조건을 그대로 승인하지 않고 입고검사부터 Cell 안전시험까지 연결했습니다.

4M 원인 지도

4M후보확인 근거판정·조치
Man공급사·검사자별 판정 차이도면·성적서·입고치수를 같은 항목으로 대조입고·공정·출하 판정 역할을 분리했습니다.
Machine기존 Knife·Crimping/Sizing Setting 부적합총고·내경·형상과 밀봉결과 비교Knife 높이·깊이·압력과 가압량·높이를 다시 맞췄습니다.
Material합금 물성·바닥부 두께 차이기존품과 후보품의 성적서·치수·외관 비교변경점을 Cell 공정과 안전성 시험까지 추적했습니다.
Method부품 승인과 Cell 검증순서 부재단품검사만으로 밀봉·파단압을 판정할 수 없음입고→조립→절단·해체→안전시험 Gate를 정했습니다.

직접 조치

  • 변경점 검토와 조립공정 시험순서를 정했습니다.
  • Beading Knife의 높이·깊이·압력을 다시 설정했습니다.
  • Crimping·Sizing의 가압량과 높이를 조정했습니다.
  • Sample 평가표, 변경점 검토서, IQC 기준, 부품 Spec, 한도견본과 공정조건을 정리했습니다.

재시험

  • Lot당 200 Cell씩 3개 Lot, 총 600 Cell을 제작했습니다.
  • 총고·내경·외관·기밀·용접부와 후속 공정 결과를 같은 기준으로 비교했습니다.
  • 용접부 절단과 Cell 해체로 내부 영향을 확인했습니다.
  • 낙하, Vent 파단압, 상·하부 압축시험과 공식 UN38.3 시험을 확인했습니다.

판정

  • 공식 UN38.3 시험을 통과했습니다.
  • 2025년 3월 기존재고 소진 후 Pilot 후속 생산분과 구매를 대체 Can으로 전환했습니다.
  • 상업 양산은 회사 자금 사정으로 가동되지 않아 장기 대량생산 결과는 확인하지 않았습니다.

역할과 승인 경계

구분담당
공정기술변경점 위험분석, 조건 설정, Sample 제작·평가와 기준 정리
품질입고·출하품질 판정
전지기술소재 차이에 따른 Cell 성능 영향 검토
구매공급사·발주와 구매 전환
최종 승인개발·전지·기술·품질·생산·구매 관련 책임자 공동 검토
결과로 사용하지 않는 항목
  • 견적과 계획물량으로 검토한 원가절감 가능성은 실현성과가 아니므로 KPI와 결과에서 제외합니다.
  • Pilot 공급 전환을 상업 양산 완료로 표현하지 않습니다.
  • 장기 대량생산의 품질·공급효과는 확인하지 않았습니다.
