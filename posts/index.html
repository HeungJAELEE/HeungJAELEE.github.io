기술 사례

프로젝트를 제조, 제조 DX, 제조 AX와 개인 AI 활용의 네 분야로 나눴습니다. 각 사례에는 문제, 직접 담당, 결과와 다음 적용방향을 정리했습니다.

01 · MANUFACTURING

제조 프로젝트

공정개발, 설비검증, 양산 안정화와 작업표준화 프로젝트입니다.

양산 적용

2170 조립라인 수율 안정화

문제 표시수율과 실제 양품수율, 현장 체감 불량이 서로 달라 공정조건보다 측정·판정체계를 먼저 확인해야 했습니다.

직접 담당 조립공정 시험과 부서 간 조정을 맡아 측정·Sensor, 검사·Vision, Jig·소모품, Recipe 순으로 원인을 좁혔습니다.

결과·현재 단계 팀 결과로 2024년 12월 월평균 실질 양품수율 98.7%를 기록했고, MSA 기준·SOP·QCP·P-FMEA·검사기준을 직접 개정했습니다.

상세 사례
제한 생산 검증

4695 양산 전환 검증

문제 개발은 끝났지만 Start부터 종료까지 정상 Auto Cycle이 되는 설비가 없어 초기 SAT 수준으로 생산 시작조건을 다시 확인해야 했습니다.

직접 담당 조립공정 시험방향을 정하고 기술·보전·제조의 Sensor·Sequence·Speed·정렬 조치와 Punch 재시험을 조율했습니다.

결과·현재 단계 대표설비 Auto Cycle을 복구하고 100 Cell×2 Lot와 마지막 50 Cell을 생산 시작 판단자료로 사용했습니다. 장기 양산 안정화는 별도 범위입니다.

상세 사례
시양산·Qual 완료

25P LFP Cell 개발

문제 해외 고객 요청의 LFP Power Cell은 소재·구조 변화가 커 기존 Cell의 함침·용접·검사조건을 그대로 사용할 수 없었습니다.

직접 담당 개발 착수부터 공정별 조건 설정, Sample 제작, 검사·평가와 문서 작성을 수행하고 공동 검토를 연결했습니다.

결과·현재 단계 A·B·C Sample과 약 2만 Cell 시양산, 2025년 3월 고객 Qual·양산 승인까지 진행했지만 단가 문제로 상업 양산은 진행되지 않았습니다.

상세 사례
A Sample 컨셉 검증

2170 Tabless A Sample 제작검증

문제 집전판을 쓰는 Tabless 구조는 기존 Lead Tab 공정과 달라 전용 Jig와 검사방법 없이 반복 제작하기 어려웠습니다.

직접 담당 4695 설비에 맞춘 임시 Jig를 제작하고 공정조건·수동조립·용접·검사와 성능평가를 담당했습니다.

결과·현재 단계 약 100개의 탐색 제작에서 기능평가 가능한 Sample 5개를 확보했습니다. 반복생산·양산성·통계적 우월성은 확인하지 않은 A Sample 단계입니다.

Pilot·검증

NCM 각형 Pilot Line 인수·초기 안정화

문제 FAT의 제한된 Sample과 개별 Auto Cycle만으로는 전후공정 연결, 반복성과 실제 생산 준비를 판단할 수 없었습니다.

직접 담당 검수 Sheet와 Punch List를 만들고 업체 조치·재시험을 추적했으며, 실제 Cell 생산과 측정·공정기준 정리를 맡았습니다.

결과·현재 단계 약 5일·약 1,000 Cell에서 재작업 후 기준 충족품을 포함한 초기 팀 Snapshot 약 95%를 확인하고 FAT/SAT·MSA·운영기준을 남겼습니다. FPY나 장기 양산수율은 아닙니다.

대체 Can 공급사 Pilot 전환

직접 담당 소재 물성과 바닥 형상 차이가 Beading·Crimping·밀봉에 미치는 영향을 나누고 조립공정 조건과 검증 순서를 직접 정했습니다.

결과·현재 단계 600 Cell·3개 Lot와 공식 UN38.3 시험을 통과한 뒤 기존재고 소진 시점부터 Pilot 후속 생산분과 구매를 대체 Can으로 전환했습니다.

상세 사례
Pilot 공정 검증

NCM Pre-Forming 공정검증

문제 Pre-Welding 전 수작업 성형은 작업자마다 위치와 형상이 달라 양·음극 무지부 손상과 Short 위험이 반복됐습니다.

직접 담당 양극과 음극의 손상 원인을 나눠 임시 Jig와 형상·위치·합격기준을 직접 만들고 Sample 시험과 해체분석을 진행했습니다.

결과·현재 단계 약 400개 Sample로 조건을 확인해 후속 Pilot 생산에 사용하고, 공정·검사기준과 P-FMEA·양산설비 RFQ에 반영했습니다.

진공로봇 Overhaul 작업표준화

양산 적용

OLED 고내열 Anodizing 피막개발
