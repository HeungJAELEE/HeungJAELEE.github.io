CASE CATALOG

기술 사례

제조 현장에서의 성과, 판단이 중요했던 실패 사례, 그리고 제조 DX·개인 AI 프로젝트를 한데 모았습니다. 각 사례가 지금 어느 단계까지 왔는지와 제가 맡은 역할을 함께 정리했습니다.

01 · MANUFACTURING

제조 현장 프로젝트

현장 문제를 확인하고 원인을 좁혀 공정·설비 조건을 바꾼 뒤 다시 시험해 작업표준으로 남긴 사례입니다.

양산 적용

2170 조립라인 수율 안정화

표시수율과 실제 양품수율, 현장 체감 불량이 서로 달라 공정조건보다 측정·판정체계를 먼저 확인해야 했습니다.

현장 결과·남긴 기준 팀 결과로 2024년 12월 월평균 실질 양품수율 98.7%를 기록했고, MSA 기준·SOP·QCP·P-FMEA·검사기준을 직접 개정했습니다.

상세 사례
제한 생산 검증

4695 양산 전환 검증

개발과 인계는 끝났지만 Auto Cycle과 Vision이 정상 작동하지 않아 작업자가 각 유닛을 수동으로 움직였고 MES 이력도 정상적으로 남지 않았습니다.

현장 결과·남긴 기준 약 2주간 2개 Lot, 약 200개로 복구시험을 진행한 뒤 마지막 50개 One-way Run에서 FYD 90% 이상을 확인해 제한 생산 시작조건으로 판단했습니다.

상세 사례
시양산·Qual 완료

25P LFP Cell 개발·시양산

LFP Power Cell은 소재와 구조가 달라 기존 2170 조건을 그대로 적용하면 조립·검사공정에서 불량이 배출됐습니다.

현장 결과·남긴 기준 A·B·C Sample과 초기 약 2만 Cell 시양산을 거쳐 고객 Qual과 CCB P.O 승인을 받았습니다. 단가 문제로 상업 양산은 진행되지 않았습니다.

상세 사례
A Sample 컨셉 검증

2170 Tabless A Sample 제작검증

집전판을 쓰는 Tabless 구조는 기존 Lead Tab 공정과 달라 전용 Jig와 검사방법 없이 반복 제작하기 어려웠습니다.

현장 결과·남긴 기준 약 100개의 탐색 제작을 거쳐 기능 검증용 Sample 5개를 확보했고, 동일 소재·동일 충방전 조건의 제한 비교에서 IR 저감과 수명 개선 방향을 확인했습니다.

상세 사례
Pilot·검증

NCM 각형 Pilot Line 인수·초기 안정화

FAT의 제한된 Sample과 개별 Auto Cycle만으로는 전후공정 연결, 반복성과 실제 생산 준비를 판단할 수 없었습니다.

현장 결과·남긴 기준 약 5일간 약 1,000 Cell에서 재작업 후 기준 충족품을 포함한 초기 조립수율 약 95%를 확인했습니다.

상세 사례
현장 표준화

진공로봇 Overhaul 작업표준화

작업자 경험에 의존하던 분해·조립과 검사 순서 때문에 작업시간과 누락 항목이 달라졌습니다.

현장 결과·남긴 기준 재작업과 잔업이 줄어드는 흐름을 확인했고, 같은 기간 팀 월 출하 실적은 1–2대에서 4–5대로 늘었습니다.

상세 사례
양산 적용

OLED 고내열 Anodizing 피막개발

고온 반복 사용에서 피막 균열과 Particle이 발생해 보증수명 안에 고객 VOC가 반복됐습니다.

현장 결과·남긴 기준 개선 조건을 양산에 적용하고 기존 조건 제품이 섞인 과도기를 거쳐 약 1년간 적용 상태를 확인했습니다.

상세 사례
양산 적용

글로벌 장비사 CVD·PECVD 부품 기술 Qual

사내 공정 결과가 안정적이어도 고객 측정방법과 기준이 다르면 Qual에서 같은 결과로 인정받기 어려웠습니다.

현장 결과·남긴 기준 동일 Sample의 측정 상관성을 확보하고 기술 Qual 승인조건을 QCP·Run Sheet·검사기준에 반영했습니다.

상세 사례
실패 사례

Diffuser 초음파 박리 Scale-up 실패 분석

Lab 박리는 가능했지만 중첩된 초음파 영역에서 표면 손상이 생겼고 조도·Diffusion·재사용성 위험이 남았습니다.

현장 결과·남긴 기준 정상 운영에는 실패했으며, 박리 가능성과 제품 재사용 가능성을 따로 판정해야 한다는 원칙을 남겼습니다.

상세 사례
Pilot 공급 전환

대체 Can 공급사 Pilot 전환

기존 공급사의 생산능력만으로 후속 생산 수요를 맞추기 어려워 신규 Can 공급사의 제조·품질 적합성을 확인해야 했습니다.

현장 결과·남긴 기준 600 Cell·3개 Lot와 공식 UN38.3 시험을 통과한 뒤 기존재고 소진 시점부터 Pilot 후속 생산분과 구매를 대체 Can으로 전환했습니다.

상세 사례
Pilot 공정 검증

NCM Pre-Forming 공정검증

Pre-Welding 전 수작업 성형은 작업자마다 위치와 형상이 달라 양·음극 무지부 손상과 Short 위험이 반복됐습니다.

현장 결과·남긴 기준 약 400개 Sample로 조건을 확인해 후속 Pilot 생산에 사용하고, 공정·검사기준과 P-FMEA·양산설비 RFQ에 반영했습니다.

02 · AI & DX

제조 DX 프로젝트

현장에서 생기는 문제를 데이터와 시스템으로 어떻게 풀었는지, 제가 만든 범위와 현재 단계를 설명합니다.

프로토타입

Indy7 로봇 Digital Twin 구현 프로젝트

PC와 티치펜던트가 작업 데이터를 주고받을 때 JSON 참조를 보존하고, 로봇 명령과 상태 확인 경로를 한 흐름으로 정리해야 했습니다.

검증 결과·현재 단계 Robot Controller에 IndyDCP 명령 경로를 모으고, Robot A·B·C 상태를 읽기 전용 화면과 이력 저장 경로로 분리해 Digital Twin 구현 범위를 정리했습니다.

상세 사례
교육 팀 PoC

용접 사진에서 불량을 찾는 AI 모델 만들기

공개 데이터에서 잘 맞는 모델이 조명·각도·표면상태가 다른 현장 사진에서도 불량을 놓치지 않는지 확인해야 했습니다.

검증 결과·현재 단계 제한된 현장 평가에서 공개 데이터와의 차이를 확인하고, 미검출을 우선해 모델과 임계값을 비교하는 평가 절차를 만들었습니다.

상세 사례
교육 팀 PoC

Factory I/O 가상공장 확장 시나리오

목표 생산량을 맞추려면 설비를 늘리기 전에 Cycle Time, 설비 수와 배치를 함께 검토해야 했습니다.

검증 결과·현재 단계 Factory I/O–PLC–SCADA–OPC UA 통신과 목표 생산량에 맞춘 가상 확장 시나리오를 교육 시연으로 연결했습니다.

상세 사례
현장 적용·인계

공정별로 끊긴 데이터를 Cell S/N으로 연결한 생산이력 추적 도구

공정별 MES는 있었지만 한 Cell의 전체 이력이 연결되지 않아 고객 요청 10개 Cell을 조사하는 데 약 3일이 필요했습니다.

검증 결과·현재 단계 단일 검색은 5–10초, 10개 Cell 전체 조사는 약 3분으로 줄였고 재직 당시 현장에 적용해 담당자에게 인계했습니다.

03 · PERSONAL AI

개인 AI 프로젝트

학습, 지식 검색과 정보 안내에 AI를 적용하며 직접 설계하고 운영하거나 실험한 작업입니다.

프로토타입

제조 지식을 모아 검색하는 HeungTology

제조·반도체·배터리 지식이 파일마다 다른 용어와 링크로 쌓여 필요한 근거를 다시 찾기 어려웠습니다.

검증 결과·현재 단계 현재 공개 main에서 지식 저장소, 링크 그래프 인덱스와 `--sync`·질의 흐름을 확인할 수 있습니다.

상세 사례
학습 아카이브

딥러닝 모델을 배우며 정리한 학습 기록

예제 코드를 한 번 실행하는 것과 데이터·설정·평가를 다시 설명할 수 있는 실험은 다릅니다.

검증 결과·현재 단계 현재 공개 main은 학습 주제와 실험 기준을 모은 README 기반 아카이브입니다.

상세 사례
운영 중

설비보전기사 수험생을 위한 학습 마스터북

자격시험 자료는 정답·이론·이미지 권리가 서로 다른 근거에 있어 AI가 자연스럽게 채우면 잘못된 학습을 만들 수 있습니다.

검증 결과·현재 단계 근거가 확인된 항목만 공개하고 충돌하거나 권리가 불분명한 항목은 HOLD로 유지하는 수험생용 마스터북을 운영하고 있습니다.

상세 사례
운영 중

실업급여 질문을 정리한 안내 가이드북

실업급여는 퇴사 사유, 근무 기간, 서류와 개인 통지 내용에 따라 결과가 달라집니다. 그래서 사이트가 자격 여부를 대신 단정하지 않도록 했습니다.

검증 결과·현재 단계 사용자가 결론을 바로 받기보다 확인할 사실과 서류, 공식 경로를 찾을 수 있는 가이드북을 운영하고 있습니다.

상세 사례
로컬 Foundation

근거를 확인한 뒤 실행하는 AI Agent 실험

AI가 자료를 읽고 행동을 제안했다는 사실만으로 실제 실행 권한과 안전한 결과를 보장할 수 없습니다.

검증 결과·현재 단계 현재는 서로 다른 LLM과 데이터에서 판단이 어떻게 달라지는지, 사람이 어디서 승인해야 하는지를 확인하는 로컬 Foundation 단계입니다.
