기술 사례

프로젝트를 제조, 제조 DX, 제조 AX와 개인 AI 활용의 네 분야로 나눴습니다. 각 사례에는 문제, 직접 담당, 결과와 다음 적용방향을 정리했습니다.

01 · MANUFACTURING

제조 프로젝트

공정개발, 설비검증, 양산 안정화와 작업표준화 프로젝트입니다.

양산 적용

2170 조립라인 실질 양품수율 안정화

문제 설비 표시수율과 사후 전수검사 양품수율이 달라 실제 공정불량과 검사 오판정을 같은 기준으로 다시 나눠야 했습니다.

직접 담당 수율 분모와 측정기준을 맞추고, 공정별 4M+2E 분석과 동일 Cell 재시험의 담당·기한·판정기준을 운영했습니다.

결과·현재 단계 팀 기준 월평균 실질 양품수율을 약 40%에서 98.7%로 안정화하는 데 기여하고 MSA 기준·SOP·QCP·P-FMEA·검사기준을 직접 개정했습니다.

상세 사례
제한 생산 검증

4695 조립설비 Auto Cycle 복구 및 제한 생산 전환

문제 Start부터 종료까지 자동으로 이어지는 설비가 없고 정상 MES 이력도 남지 않아, 조립 전공정의 생산 시작조건을 초기 SAT 기준으로 다시 확인해야 했습니다.

직접 담당 조립 전공정 시험방향과 판정기준을 정하고, 공정별 4M+2E·Punch 담당·기한·재시험을 운영했습니다.

결과·현재 단계 100 Cell×2 Lot 재시험과 최종 50 Cell One-way Run으로 제한 생산 시작조건을 확인하고 작업표준·QCP·P-FMEA·Check List·MES 관리항목을 개정·제정했습니다.

상세 사례
시양산·Qual 완료

25P LFP Power Cell 공정조건 개발 및 시양산 검증

문제 기존 2170과 전해액·Clad Tab·Turn 수·Can 높이·검사조건이 함께 달라 함침부터 후공정까지 공정조건을 다시 정해야 했습니다.

직접 담당 개발 착수부터 CTQ와 변경점을 공정별 4M+2E 시험으로 바꾸고 Sample 제작·검사·평가·Gate와 표준문서를 운영했습니다.

결과·현재 단계 A·B·C Sample, 약 2만 Cell 시양산, 고객 Qual과 CCB P.O 승인을 완료했으며 단가 문제로 상업 양산은 진행되지 않았습니다.

상세 사례
A Sample 컨셉 검증

2170 Tabless 구조 A Sample 제조성 검증

문제 전용설비와 Jig가 없는 상태에서 기존 4695 설비로 Tabless 구조를 만들면서 내부 Laser Beam 유입·Short·조립손상 위험을 함께 확인해야 했습니다.

직접 담당 공정조건과 임시 3D Print·Jig를 정하고 Sample 제작, Laser Welding, 조립, 절단·해체, Hi-Pot과 기능평가를 직접 수행했습니다.

결과·현재 단계 약 100개 탐색 제작에서 실패형태를 분리하고 기능 Sample 5개를 확보해 A Sample 구조 제작가능성과 기능방향을 확인했습니다.

Pilot·검증

NCM 각형 Pilot Line 인수·초기 안정화

문제 FAT의 제한 Sample과 개별 Auto Cycle만으로는 현장 전후공정 연결, 제품품질과 생산 준비를 판단할 수 없었습니다.

직접 담당 사양·인수기준과 검수 Sheet를 만들고 FAT·SAT·Punch 재시험, 실제 Cell 공정조건·측정방법과 초기 생산운영을 직접 맡았습니다.

결과·현재 단계 핵심설비 11대·주요공정 13개를 약 5일·약 1,000 Cell 생산으로 연결했고, 재작업 후 기준충족품을 포함한 초기 조립 결과 약 95%와 운영기준을 팀 결과로 확인했습니다.

상세 사례
Pilot 공급 전환

대체 Can 공급사 600 Cell·3 Lot Pilot 전환 검증

문제 기존 Can 공급사 한 곳만으로 계획 생산물량을 대응하기 어려웠고, 후보품의 합금·두께·공차·Burr 차이가 조립·밀봉·안전성에 미치는 영향을 확인해야 했습니다.

직접 담당 변경점·입고검사부터 Beading·Crimping/Sizing·Laser 조건, Sample Cell, 절단·해체, 안전·성능시험과 기준문서를 직접 맡았습니다.

결과·현재 단계 Lot당 200 Cell씩 3개 Lot와 공식 UN38.3를 통과하고, 2025년 3월 Pilot 후속 생산분과 구매발주를 대체 Can으로 전환했습니다.

상세 사례
Pilot 공정 검증

NCM Pre-Forming 공정검증

문제 Pre-Welding 전 수작업 성형은 작업자마다 위치와 형상이 달라 양·음극 무지부 손상과 Short 위험이 반복됐습니다.

직접 담당 양극과 음극의 손상 원인을 나눠 임시 Jig와 형상·위치·합격기준을 직접 만들고 Sample 시험과 해체분석을 진행했습니다.

결과·현재 단계 약 400개 Sample로 조건을 확인해 후속 Pilot 생산에 사용하고, 공정·검사기준과 P-FMEA·양산설비 RFQ에 반영했습니다.

반도체·디스플레이 이송로봇 Overhaul 표준체계 구축

문제 YMC 신규사업 초기에는 신규 기종의 Parts List, 분해·조립·작동·검사 Manual과 정도 Setting 기준이 없었습니다.

혼산 Anodizing Bath 분석·보충기준 표준화

결과·현재 단계 10인 팀은 Factory I/O 가상공정과 PLC·SCADA·OPC UA·Web의 정상 흐름을 시연했습니다. DQN은 State·Action과 연결위치를 정한 설계 단계로 구분했습니다.

실업급여 질문을 정리한 안내 가이드북

문제 실업급여는 퇴사 사유, 근무 기간, 서류와 개인 통지 내용에 따라 결과가 달라집니다. 그래서 사이트가 자격 여부를 대신 단정하지 않도록 했습니다.

직접 담당 비식별 질문 165건을 8개 유형으로 나누고 공식 출처, 가이드, 검색 페이지와 구조화 데이터를 하나의 원본에서 만들었습니다.

결과·현재 단계 사용자가 결론을 바로 받기보다 확인할 사실과 서류, 공식 경로를 찾을 수 있는 가이드북을 운영하고 있습니다.
