현장 문제와 결과 요약

현장 문제
YMC의 공정개발·Qual·실패·신규사업 경험을 한 글에 섞으면 각 사례의 판단기준과 완료범위가 보이지 않았습니다.
내가 맡은 일
문제·측정·원인·재시험·표준화 순서와 회사·고객·개인 역할경계를 다시 구분했습니다.
확인한 결과
Anodizing, Bath 분석, 기술 Qual, Diffuser 실패와 이송로봇 표준화의 다섯 상세 사례로 연결했습니다.

YMC에서 맡은 일

YMC 기술연구소에서는 표면처리 조건을 만드는 일부터 약액을 관리하는 방법, 고객 Qual, 실패한 Scale-up의 중단판정과 신규 로봇사업의 작업표준까지 맡았습니다. 공통점은 하나였습니다. 현상을 보고 조건부터 바꾸지 않고, Sample·측정방법·공정이력부터 맞춘 뒤 원인을 좁혀 재시험하고 문서로 남기는 것이었습니다.

대학 4학년 때 취득한 Six Sigma Green Belt의 문제해결 순서를 실무에 사용했습니다. 당시 YMC 업무가 Charter와 Tollgate를 운영한 공식 Six Sigma 과제였던 것은 아닙니다. 현상과 분모를 정하고, 4M·5 Why·Pareto와 비교시험으로 후보를 줄인 뒤 재시험과 표준화로 닫았다는 의미에서 DMAIC 관점으로 설명합니다.

프로젝트를 다섯 가지로 나눈 이유

사례시작 질문내가 맡은 범위완료·판정
고내열 Anodizing 공정개발높아진 공정온도와 신규 고온조건에서 피막이 버틸 수 있는가Sample 제작, 열·내전압 평가, 소형→대면적 확대, 고객 Qual혼산·수산 조건 고객 Qual 및 제품 적용
혼산 Bath 분석·보충기준분석값은 정상인데 왜 3개월 이후 제품성능이 떨어지는가Sampling, 성분별 분석·제품 Sample 비교, 외부검토, 한국·중국 적용대상 Bath의 분석·보충·교체 판단기준 표준화
CVD·PECVD 부품 기술 Qual사내와 고객의 측정값이 다를 때 무엇을 먼저 맞춰야 하는가영문 Spec, Process·Run Sheet, Sample, Hi-Pot Correlation, 기술실사지적사항 재시험 종료와 기술 Qual
Diffuser 초음파 박리박리시간을 줄이면서 표면·재사용성을 지킬 수 있는가Lab·실물시험, 손상분석, Scale-up 위험과 중단조건 정리정상운영 중단, 다음 과제의 Stop Gate 도출
이송로봇 Overhaul 표준체계Parts List와 Manual이 없는 신규 기종을 반복 작업 가능한 기준으로 바꿀 수 있는가분해·조립·Align·Zero·Leak·정도검사, Manual·교육YMC 초도 Qual 후 본테크 운영표준으로 확장

상세 사례

1. 고내열 Anodizing 공정개발

혼산 Upper Electrode의 양산 안정화와 수산 Susceptor의 신규 고온 Qual은 같은 Anodizing 기술을 사용했지만 시작점이 달랐습니다. 한 페이지 안에서 두 Case로 나눠 시험조건과 완료범위를 구분했습니다.

디스플레이 장비부품 고내열 Anodizing 공정개발

2. 혼산 Bath 분석·보충기준 표준화

기존에는 하나의 적정값을 초기 조성비로 환산해 보충했지만, Bath가 사용되면서 각 성분의 실제 소모속도가 달랐습니다. 약액 숫자만 보지 않고 Batch Sample의 피막결과와 연결해 분석·보충기준을 다시 만들었습니다.

혼산 Anodizing Bath 분석·보충기준 표준화

3. 글로벌 장비사 기술 Qual

같은 물리적 Sample을 양쪽에서 돌린 사례가 아닙니다. 동일 Bath·동일 제조조건으로 만든 대응 Sample을 고객 지정 위치와 반복횟수로 측정하고, 장비·시험순서·Arc 판독조건을 맞춰 차이를 닫았습니다.

글로벌 디스플레이 장비사 CVD·PECVD 부품 기술 Qual

4. Diffuser 초음파 박리 실패

초기 제한시험에서는 시간이 줄었지만 환경안전 제약으로 약액을 사용할 수 없게 되면서 조건 자체가 달라졌습니다. 이후 작업시간과 수작업이 늘고 Cavitation Erosion이 누적돼 재사용성 Gate를 통과하지 못했습니다.

Diffuser 초음파 박리 Scale-up 실패와 Stop Gate

5. 이송로봇 Overhaul 표준체계

YMC에서는 신규사업 초기의 Parts List·분해·조립·검사 Manual과 초도 Qual을 만들었습니다. 본테크에서는 같은 기술영역을 반복 Overhaul, 부품·작업자·설비 운영과 현장 Setup까지 확장했습니다.

반도체·디스플레이 이송로봇 Overhaul 표준체계 구축

공개 범위

공개 페이지에는 문제, 판단순서, 직접 역할, 비식별 시험구조와 표준화 결과만 사용했습니다. Bath 조성·Recipe·고객 Spec·승인서·원본 Run Sheet·장비 설정값은 포함하지 않았습니다. 오래된 자료의 불량률과 Bath 수명 수치는 분모와 실제 채택여부가 닫히지 않아 대표 성과로 사용하지 않습니다.
