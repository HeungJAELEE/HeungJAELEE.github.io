차세대 2170 Tabless 구조 A Sample 선행 제조 검증

프로젝트 핵심 요약

과제 정의
Tabless 전용 설비와 Jig가 없는 상태에서 기존 4695 설비로 신규 구조를 구현하면서 Laser Beam 유입, Short, 정렬과 조립손상을 함께 해결해야 했습니다.
핵심 역할
선행 제조공정과 임시 3D Print Jig를 구성하고 Sample 제작, Laser Welding, 조립, 절단·해체, Hi-Pot과 기능평가를 직접 수행했습니다.
주요 결과
약 100개 탐색 제작에서 Failure Mode를 분리하고 기능 Sample 5개를 확보해 A Sample의 구조 제작가능성과 전기적 기능을 확인했습니다.
탐색 제작 범위 약 100개
기능 Sample 5개

프로젝트 배경과 목표

기존 Lead Tab을 대체하는 Tabless 구조는 극판과 Collector를 넓은 면적으로 연결해 통전경로를 구성하는 신규 구조였습니다. 문제는 Tabless 전용 설비와 전용 Jig가 전혀 없는 상태에서 단기간 안에 실제 작동 가능한 2170 A Sample을 만들어야 했다는 점입니다.

기존 4695 설비의 Jig·작업조건과 공정순서를 Tabless Sample 제작에 맞게 임시 재구성했습니다. 넓은 면적을 Laser로 접합하는 과정에서는 Beam이 J/R과 Separator 내부로 들어가거나, 수작업 조립 중 정렬불량과 Short가 발생할 위험을 함께 해결해야 했습니다.

저는 선행 제조공정 설계와 Sample 제작을 맡아 공정조건, 3D Print 기반 임시 Jig, Laser Welding, 조립, 절단·해체, Hi-Pot과 기능평가를 직접 수행했습니다. 개발팀은 구조검토와 제품 요구사항, 개발문서를 담당했습니다.

선행 제조 검증 흐름

제조경로 구축. J/R 고정, Collector 정렬, Laser Welding, Can 삽입과 후공정을 하나의 임시 작업흐름으로 연결했습니다.

용접·안전 검증. 외관만으로 용접을 판단하지 않고 조건별 Sample을 절단·해체해 내부 Beam 유입과 J/R·Separator 손상을 확인했습니다. 기능평가 전에는 Hi-Pot과 Short 검사를 적용했습니다.

탐색 제작. 약 100개 Sample을 제작하면서 용접, 정렬, 삽입, 내부손상과 절연불량을 단계별 Failure Mode로 분리했습니다.

기능평가. 안전·조립조건을 충족한 기능 Sample 5개를 대상으로 IR, Formation, 충전·용량과 동일 조건의 수명비교를 진행해 Tabless 구조의 전기적 기능을 확인했습니다.

1. 전용 설비 없이 임시 제조경로 구축

3D Print 기반 임시 Jig 구성

전용 Jig가 없어 J/R과 Collector를 수작업으로 맞추면 위치가 흔들리고, Laser 용접 후 Can 삽입 과정에서 J/R 또는 Collector가 손상될 수 있었습니다.

J/R 위치를 고정하고 Collector 기준점을 맞출 수 있도록 3D Print 기반 임시 Jig를 구성했습니다. Jig별 고정상태와 Collector 위치를 비교하고, Laser Welding 전후의 정렬과 조립손상을 확인해 다음 작업으로 넘길 Sample을 선별했습니다.

4695 설비를 활용한 수동·설비 혼합 공정

기존 4695 Laser 설비에서 용접이 가능하도록 제품 기준위치와 Jig 고정방법을 맞췄습니다. 설비가 대응하지 못하는 Can 삽입과 일부 조립은 수작업 순서를 정해 연결했습니다.

J/R 고정
→ Collector 정렬
→ Laser Welding
→ 절단·해체 확인
→ Can 삽입·조립
→ Hi-Pot·Short
→ 기능평가

이 경로를 통해 전용 설비가 없는 상태에서도 용접부터 조립·검사까지 이어지는 A Sample 제조흐름을 확보했습니다.

2. Laser Beam 유입과 Short 안전 검증

Tabless 구조는 넓은 접합면을 Laser로 용접하기 때문에 외관이 정상이어도 Beam이 Cell 내부로 유입되거나 Separator를 손상시킬 수 있었습니다. 따라서 용접외관만으로 조건을 결정하지 않았습니다.

  • 조건별 용접부를 절단해 접합상태와 Beam 경로 확인
  • Cell 해체 후 J/R·Separator의 내부손상 여부 확인
  • Hi-Pot과 Short 결과를 해당 용접 Sample과 연결
  • 안전검사를 통과한 Sample만 Formation과 기능평가로 이동

절단·해체 결과를 기준으로 Jig 정렬, 고정위치, Laser 경로와 용접조건을 반복 조정했습니다. 이를 통해 A Sample 제작에 사용할 용접·안전 확인순서를 정립했습니다.

3. 약 100개 탐색 제작과 Failure Mode 분리

설비와 Jig가 완성되지 않은 A Sample 단계에서는 한 번에 정답조건을 찾기보다, 실패가 발생한 공정을 정확히 분리하는 것이 우선이었습니다.

  • Laser 용접불량: 접합형상·조건과 Jig 정렬 재확인
  • 내부 Beam 유입: 절단·해체로 J/R·Separator 손상 확인
  • Hi-Pot·Short: 용접 Sample과 절연검사 결과 연결
  • Collector 정렬불량: Jig 기준점과 수작업 위치 재조정
  • 조립손상: Can 삽입 전후 J/R·Collector 외관과 해체결과 비교
  • J/R 고정실패: 임시 Jig의 지지점과 작업순서 수정

약 100개 탐색 제작 과정에서 발생한 실패형태를 단계별로 기록하고, 원인이 확인된 Sample은 다음 제작조건에 반영했습니다. 이 기록은 전용 Jig, Laser 작업위치와 검사방법을 설계하기 위한 입력이 됐습니다.

4. 기능 Sample 5개 구현과 전기적 평가

실패형태를 순서대로 제거해 기능평가가 가능한 Sample 5개를 확보했습니다. 각 Sample은 조립과 절연 안전성을 확인한 뒤 다음 평가로 진행했습니다.

  • Hi-Pot·Short 검사
  • IR 확인
  • Formation
  • 충전·용량 평가
  • 기존 Lead Tab Cell과 동일 소재·동일 충방전 조건의 수명비교

5개 Sample에서 Tabless 구조가 정상적으로 조립되고 전기적 기능을 발현하는 것을 확인했습니다. 기존 Lead Tab 구조와의 비교에서는 IR과 수명에서 개선 방향도 함께 확인했습니다.

최종 성과와 Pilot 설계 입력

A Sample에서 확인한 결과

  • 전용 설비·Jig가 없는 조건에서 기존 4695 설비와 3D Print 임시 Jig를 이용한 제조경로 구축
  • 약 100개 탐색 제작을 통해 용접·Beam·Short·정렬·조립손상 Failure Mode 분리
  • 절단·해체·Hi-Pot을 통과한 기능 Sample 5개 확보
  • IR·Formation·충전·용량·동일조건 수명비교를 통한 구조·전기적 기능 확인
  • 차세대 2170 Tabless 구조의 A Sample 선행 제조 검증 완료

다음 Pilot 단계에 필요한 설계 입력

  • J/R 고정과 Collector 정렬을 반복 재현할 전용 Jig
  • Tabless 접합형상에 맞는 Laser 설비·작업위치와 내부손상 검사방법
  • Can 삽입·조립의 수작업 의존 제거
  • 단위공정 반복성, 검사 재현성과 생산성 검증

이번 검증에서 확보한 제조경로와 Failure Mode를 기준으로 전용 Jig·설비와 Pilot 검사요구사항을 정리했습니다.
