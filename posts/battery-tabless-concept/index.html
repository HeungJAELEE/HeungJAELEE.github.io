A Sample 컨셉 검증

차세대 2170 Tabless 구조 A Sample 선행 제조 검증 (PoC)

전용 설비·Jig 없이 기존 4695 설비와 임시 Jig로 제조경로를 구성하고 약 100개 Trial을 거쳐 기능 Sample 5개의 Cell 평가를 완료

프로젝트 기간
2025.01 · 차세대 2170 Tabless A Sample 선행 제조 검증
맥락
금양 전지기술팀 · 기존 4695 설비를 활용한 신규 Tabless 구조 A Sample
담당 범위
선행 제조공정 설계 · 3D Print 임시 Jig · Laser Welding·조립조건 · 절단·해체 · Hi-Pot·Short · Cell 평가

프로젝트 핵심 요약

과제 정의
Tabless 전용 설비·Jig 없이 기존 4695 설비와 수작업을 조합해 Laser Beam 유입, Short, 정렬과 조립손상을 통제한 A Sample을 제작해야 했습니다.
핵심 역할
선행 제조공정, 3D Print 임시 Jig, Laser Welding·조립조건, 절단·해체, Hi-Pot·Short와 Cell 평가를 직접 수행했습니다.
주요 결과
약 100개 Trial에서 Failure Mode를 분리하고 기능 Sample 5개의 Cell 평가로 Tabless 구조의 제작·기능 타당성을 확인했습니다.
탐색 제작 범위 약 100개
기능 Sample 5개

프로젝트 개요

  • 개발 과제: 기존 Lead Tab을 대체해 극판과 Collector를 넓은 면적으로 연결하는 Tabless 구조의 A Sample 제작
  • 제조 제약: Tabless 전용 설비·Jig 부재, 기존 4695 설비와 수작업을 조합해야 하는 조건
  • 핵심 위험: Laser Beam 내부 유입, Separator 손상, Collector 정렬불량, Can 삽입 중 J/R 손상과 Short
  • 직접 역할: 선행 제조공정 설계, 3D Print 임시 Jig, Laser Welding·조립조건, 절단·해체, Hi-Pot·Short, Cell 평가
  • 협업 범위: 개발팀의 구조검토·제품 요구사항과 제조시험 결과 연계

1. 전용 설비 없이 임시 제조 경로 구축

3D Print 임시 Jig

  • J/R 고정점과 Collector 기준위치를 잡는 임시 Jig 구성
  • Jig별 고정상태·정렬위치 비교
  • Laser Welding 전후 정렬과 Can 삽입 중 손상 확인
  • 다음 공정 투입 Sample 선별기준 설정

기존 4695 설비와 수작업 공정 연결

  • Laser 설비의 제품 기준위치와 Jig 고정방법을 Tabless Sample에 맞게 재설정
  • 설비가 대응하지 못하는 Can 삽입·일부 조립은 표준 수작업 순서로 연결
  • 용접부터 안전검사·Cell 평가까지 하나의 Sample 제조 흐름으로 구성
J/R 고정
→ Collector 정렬
→ Laser Welding
→ 절단·해체
→ Can 삽입·조립
→ Hi-Pot·Short
→ Cell 평가

2. Laser Beam 유입·Short 사전 차단

파괴검사 — 절단·해체

  • 조건별 용접부 절단으로 접합상태와 Beam 경로 확인
  • Cell 해체 후 J/R·Separator 내부손상 확인
  • 결과에 따라 Jig 정렬, 고정위치, Laser 경로와 용접조건 재조정

비파괴검사 — 절연 Gate

  • 조립 Sample 전량 Hi-Pot·Short 확인
  • 절연·조립 안전기준을 충족한 Sample만 후속 Cell 평가 진행
  • 용접 Sample과 절연결과를 연결해 불량 발생공정 추적

3. 약 100개 Trial과 Failure Mode 분리

약 100개 탐색 제작에서 실패 위치를 공정별로 분리하고, 확인 결과를 다음 제작조건에 즉시 반영했습니다.

  • Laser 용접불량: 접합형상·조건·Jig 정렬 재검토
  • 내부 Beam 유입: 절단·해체로 J/R·Separator 손상 확인
  • Hi-Pot·Short: 용접 Sample과 절연결과 연계
  • Collector 정렬불량: Jig 기준점·수작업 위치 수정
  • Can 삽입 손상: 삽입 전후 J/R·Collector 상태 비교
  • J/R 고정실패: Jig 지지점·고정순서 재구성

Trial 기록은 후속 Pilot의 전용 Jig, Laser 작업위치, 조립방식과 검사방법을 정하는 근거로 정리했습니다.

4. 기능 Sample 5개 Cell 평가

안전·조립기준을 충족한 기능 Sample 5개를 선별해 Cell 평가를 진행했습니다.

  • Hi-Pot·Short
  • IR
  • Formation
  • 충전·용량
  • 기존 Lead Tab Cell과 동일 소재·동일 충방전 조건의 수명 비교

평가 결과, Tabless 구조의 정상 조립과 전기적 기능 발현을 확인했습니다. 기존 Lead Tab 구조와의 비교에서는 IR·수명 개선 방향을 확인했습니다.

최종 성과

  • 기존 4695 설비와 3D Print 임시 Jig를 활용한 Tabless A Sample 제조경로 구축
  • 약 100개 Trial에서 용접·Beam·Short·정렬·조립손상 Failure Mode 분리
  • 절단·해체·Hi-Pot 안전검사를 통과한 기능 Sample 5개 확보
  • IR·Formation·충전·용량·수명 비교를 통한 Cell 타당성 확인
  • 차세대 2170 Tabless 구조 A Sample 선행 제조 PoC 완료

차후 설계 반영 사항

  • 설비·Jig: J/R 고정과 Collector 정렬 산포를 억제하는 전용 Jig
  • Laser: Tabless 접합형상에 맞는 작업위치·광학조건과 내부손상 검사방법
  • 조립: 수작업 Can 삽입 제거와 자동 조립경로 구성
  • 검사: 내부손상 검사 표준화와 자동검사 적용 가능성 검토
  • Pilot 검증: 단위공정 반복성, 검사 재현성, 생산성 확인

A Sample Trial에서 확인한 제조 제약과 Failure Mode를 위 항목으로 정리해 후속 Pilot 검토에 이관했습니다.
