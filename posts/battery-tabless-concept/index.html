TECHNICAL CASE STUDY

2170 Tabless 셀 개발 (Pilot Lv)

사내 개발품질 절차의 PROTO(A Sample) Gate에서 DMADV로 목표와 안전 CTQ를 정의하고, 4M 위험맵과 DFMEA로 전용 설비·Jig가 없는 제조경로의 불량 유형과 근본 원인을 좁혀 약 100개 Trial과 기능 Sample 5개의 Cell 평가를 완료한 선행 제조 PoC

2026. 8. 3. · 5 · 마지막 검토 2026. 8. 9.

  • IATF 16949
  • DMADV
  • DFMEA
  • Tabless
  • A Sample

프로젝트 개요

  • 개발 과제: 기존 Lead Tab을 대체해 극판과 Collector를 넓은 면적으로 연결하는 2170 Tabless 구조 A Sample 제작
  • 품질 프로세스: 사내 IATF 16949 기반 PROTO(A Sample) → PILOT(B·C Sample) → MP(CCB.PO) → SOP(양산)
  • 현재 완료 Gate: PROTO A Sample 제조·Cell 평가 완료
  • 제조 제약: Tabless 전용 설비·Jig 부재, 기존 4695 Laser 설비와 수작업을 조합해야 하는 조건
  • 핵심 CTQ: 접합상태, 내부 Beam 유입·Separator 손상, 절연·Short, IR·Formation·용량·수명
  • 직접 역할: 선행 제조공정 설계, 4M 위험분석, DFMEA, 3D Print 임시 Jig, Laser·조립조건, 절단·해체와 Cell 평가
  • 최종 결과: 약 100개 Trial에서 Failure Mode를 압축 분리하고 기능 Sample 5개의 제작·기능 타당성 확인

IATF 16949 기반 개발품질 Gate와 현재 위치

품질 단계 사내 Sample·승인 기술 목표 Tabless 프로젝트 상태
PROTO A Sample 신규 구조의 제작성, 안전 CTQ와 기본 Cell 기능 확인 완료 — 기능 Sample 5개 Cell 평가
PILOT B·C Sample 전용 Jig·설비, 반복성·검사 재현성과 생산성 검증 차후 설계 반영 사항으로 이관
MP CCB.PO·C Sample Pilot 조건의 기술 양산 승인 후속 Gate
SOP 양산 개시 승인조건의 정규 생산 운영 후속 Gate

Tabless 프로젝트의 목표는 PROTO 단계에서 신규 구조를 실제 Cell로 구현하고 안전·기능 타당성을 확인하는 것이었습니다. 시험 결과는 PILOT B·C Sample의 전용 Jig·설비·검사 요구사항으로 이관했습니다.

PROTO Gate 내부 DMADV

DMADV 실제 수행 판단·산출물
Define No Eq·No Jig 조건에서 작동 가능한 Tabless A Sample 제작, 안전·기능 CTQ 정의 제조 제약, 직접 역할, 성공기준
Measure 접합상태, 내부 Beam 유입, Separator 손상, Hi-Pot·Short와 Cell 평가항목 연결 절단·해체·절연·IR·Formation·용량·수명 기준
Analyze 4M로 Jig·설비·소재·수작업 후보를 분리하고 검사 신뢰성을 별도로 확인해 Failure Mode 우선순위 설정 핵심 위험맵과 Trial 인자
Design 기존 4695 설비, 3D Print Jig와 수작업 조립을 연결하고 DFMEA로 Failure Mode·원인·검증항목을 연결 임시 제조경로, Jig·Laser·조립 조건
Verify 약 100개 Trial의 실패형태를 단계별로 줄이고 기능 Sample 5개를 Cell 평가 A Sample 제작·기능 타당성, 차후 설계 반영 사항

4M 핵심 위험맵

분석대상 추정원인 확인결과 조치사항
Man J/R·Collector 정렬, Can 삽입과 조립의 수작업 편차 작업순서별 정렬·손상·Short 결과 · Measure·Analyze 고정순서와 Sample 선별기준 설정
Machine 전용 설비·Jig 부재, 4695 Laser 기준위치와 임시 Jig 지지점 Jig별 고정상태, 용접위치와 조립결과 · Analyze·Design 제품 기준위치·Jig 고정방법·지지점 설계
Material 기존 Cell과 동일 소재, Tabless 접합구조 변경 동일 소재·충방전 조건에서 Lead Tab 구조와 비교 · Define·Analyze 소재변수는 고정하고 구조·공정영향에 집중
Method J/R 고정, Collector 정렬, Laser 경로·조건, Can 삽입순서 조건별 절단·해체와 Failure Mode 기록 · Analyze·Design DFMEA의 원인·예방·검출 항목으로 연결

측정·환경 확인

  • Measurement: 접합단면, 내부 Beam·Separator, Hi-Pot·Short, IR·Formation·용량·수명 · 파괴·비파괴검사와 Cell 평가 결과 · Measure·Verify · 안전 Gate 통과품만 기능 Sample로 확정

DFMEA [불량 유형별 근본 원인(Root Cause) 도출 매트릭스]

약 100개 Trial은 무작위 반복이 아니었습니다. 4M에서 확인한 Jig·Laser·조립 변수를 불량 유형, 추정 원인, 예방·검출 항목으로 연결하고, 각 Trial의 절단·해체·전기검사 결과로 다음 조건을 좁혔습니다.

인자군 비교한 조건 주요 반응값 설계 판정
Jig·정렬 J/R 지지점, Collector 기준점, 고정방법 정렬산포, J/R 고정실패, 삽입 중 손상 정렬과 고정이 유지되는 임시 Jig 구성
Laser 제품 기준위치, 용접경로, 접합조건 용접불량, 내부 Beam 유입, Separator 손상 절단·해체에서 내부손상이 없는 조건 채택
조립 Can 삽입방향·순서, 수동 조립방법 Collector 이동, J/R 손상, Hi-Pot·Short 조립손상을 줄이는 표준 수작업 흐름 설정
확인실험 선정 Jig·Laser·조립 조합 Hi-Pot·Short, IR, Formation, 충전·용량·수명 기능 Sample 5개 Cell 평가로 최종 확인

1. 임시 제조경로 설계

3D Print 임시 Jig

  • J/R 지지점과 Collector 기준위치를 고정하는 임시 Jig 설계·적용
  • Jig별 고정상태·정렬위치와 Can 삽입 중 손상 비교
  • Laser Welding 전후 정렬을 확인해 다음 공정 투입 Sample 선별
  • Trial 결과에 따라 지지점·고정방법·작업순서 반복 수정

기존 4695 설비와 수작업 연결

  • Laser 설비의 제품 기준위치와 Jig 고정방법을 Tabless Sample에 맞게 재설정
  • 설비가 대응하지 못하는 Can 삽입·일부 조립은 표준 수작업 순서로 연결
  • 용접부터 안전검사·Cell 평가까지 최소 제조흐름 구성
J/R 고정
→ Collector 정렬
→ Laser Welding
→ 절단·해체
→ Can 삽입·조립
→ Hi-Pot·Short
→ Cell 평가

2. Laser Beam 유입·Short 차단

파괴검사

  • 조건별 용접부 절단으로 접합단면과 Beam 경로 확인
  • Cell 해체 후 J/R·Separator 내부손상 확인
  • 결과를 Jig 정렬·고정위치·Laser 경로와 다음 Trial 조건에 반영

비파괴검사

  • 조립 Sample의 Hi-Pot·Short 확인
  • 절연·조립 안전기준 충족품만 Cell 평가 진행
  • 용접 Sample과 절연결과를 연결해 불량 발생공정 분리

3. 약 100개 Trial과 Failure Mode 축소

  • Laser 용접불량: 접합형상·조건·Jig 정렬 재설계
  • 내부 Beam 유입: 절단·해체로 J/R·Separator 손상 확인
  • Hi-Pot·Short: 용접·조립 Sample과 절연결과 연계
  • Collector 정렬불량: Jig 기준점·고정방식 수정
  • Can 삽입 손상: 삽입 전후 J/R·Collector 상태 비교
  • J/R 고정실패: Jig 지지점·고정순서 재구성

Failure Mode를 공정별 반응값으로 관리해 다음 Trial의 인자조합을 좁혔습니다. 이 과정에서 확보한 조건과 실패기록은 전용 Jig·Laser 작업위치·조립방식·검사방법의 차후 설계 반영 사항으로 정리했습니다.

4. 기능 Sample 5개 Cell 평가

안전·조립기준을 충족한 기능 Sample 5개를 선별해 다음 Cell 평가를 진행했습니다.

  • Hi-Pot·Short
  • IR
  • Formation
  • 충전·용량
  • 기존 Lead Tab Cell과 동일 소재·동일 충방전 조건의 수명 비교

평가 결과, Tabless 구조의 정상 조립과 전기적 기능 발현을 확인했습니다. 기존 Lead Tab 구조와의 동일조건 비교에서는 IR·수명 개선 방향을 확인했습니다.

최종 성과

  • IATF 16949 기반 개발품질 프로세스의 PROTO A Sample Gate 완료
  • DMADV로 A Sample 목표·CTQ·측정·검증조건을 하나의 선행 제조 흐름으로 구성
  • 4M 위험맵에서 Jig·Laser·조립·검사 핵심 인자 도출
  • DFMEA로 약 100개 Trial의 Failure Mode·근본 원인·검증항목 연결
  • 기존 4695 설비와 3D Print 임시 Jig를 활용한 Tabless 제조경로 구축
  • 절단·해체·Hi-Pot 안전검사를 통과한 기능 Sample 5개 확보
  • IR·Formation·충전·용량·수명 비교를 통한 A Sample 제작·기능 타당성 확인

PILOT B·C Sample 차후 설계 반영 사항

  • 설비·Jig: J/R 고정과 Collector 정렬 산포를 억제하는 정밀 전용 Jig
  • Laser: Tabless 접합형상에 맞는 작업위치·광학조건과 내부손상 검사방법
  • 조립: 수작업 Can 삽입 제거와 자동 조립경로
  • 검사: 내부손상 검사 표준화와 자동검사 적용성
  • Pilot 검증: 단위공정 반복성, 검사 재현성, 생산성

연계 프로젝트

  • 4695 조립라인 주요 설비 정상화 및 제한 생산 전환: Tabless A Sample 제작에 활용한 기존 설비의 정도·Laser·생산조건을 정상화한 사례
  • LFP Power Cell 개발: PROTO·PILOT·MP Gate를 거쳐 고객 CTQ와 기술 승인을 완료한 신규 Cell 개발 사례
  • 2170 조립라인 실질 양품수율 안정화: Tabless 선행 검증에 활용한 기존 2170 조립공정·측정·검사 기반을 안정화한 사례
