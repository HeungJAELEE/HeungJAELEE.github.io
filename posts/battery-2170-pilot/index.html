2170 조립라인 수율 안정화

표시수율을 그대로 믿지 않고 측정 오판정과 실제 공정불량을 나눈 뒤 재시험과 표준화로 이어간 양산 개선

프로젝트 기간
핵심 안정화 2024.05–2024.12 · 후속 유지 확인 2025.01–2025.02
맥락
금양 전지기술팀 재직 중 수행
담당 범위
생산·품질·설비·개발이 같은 기준으로 보도록 수율, 불량, 비가동과 재시험 결과를 정리

현장 문제와 결과 요약

현장 문제
표시수율과 실제 양품수율, 현장 체감 불량이 서로 달라 공정조건보다 측정·판정체계를 먼저 확인해야 했습니다.
내가 맡은 일
조립공정 시험과 부서 간 조정을 맡아 측정·Sensor, 검사·Vision, Jig·소모품, Recipe 순으로 원인을 좁혔습니다.
확인한 결과
팀 결과로 2024년 12월 월평균 실질 양품수율 98.7%를 기록했고, MSA 기준·SOP·QCP·P-FMEA·검사기준을 직접 개정했습니다.
실질 양품수율 약 40% → 98.7%

프로젝트 전체가 어떻게 진행됐는가

초기에는 설비 표시수율과 실제 양품수율, 현장에서 체감하는 불량이 서로 맞지 않았습니다. 초기 약 40%는 조립공정에 투입한 Cell 가운데 완전히 양품으로 판정된 수량을 사후검사로 다시 확인한 기준선입니다. 공정조건부터 바꾸면 검사 오판정과 실제 불량이 섞이기 때문에 수율 분모와 불량명, 측정·판정체계를 먼저 맞췄습니다.

  1. 2024.05–06기준선 정렬수율 분모와 불량명, 측정·검사 기준을 맞췄습니다.
  2. 2024.07–08원인 분리측정·Sensor부터 검사·Vision, Jig·정렬·소모품 순으로 후보를 좁혔습니다.
  3. 2024.09–10공정별 시험Vision, 저항용접, 주액과 후공정 조건을 사례별로 검증했습니다.
  4. 2024.11–12재검증·표준화같은 판정기준으로 다시 확인하고 현장 문서를 개정했습니다.
  5. 2025.01–02유지 확인개정한 조건과 기준이 현장에서 유지되는지 확인했습니다.

10개 Batch 이상의 전수검사와 Gage R&R, 유지 MSA 기준으로 측정체계를 확인했습니다. 확인 순서는 측정조건·Sensor → 검사·Vision → Jig·정렬·소모품 → Recipe였습니다. 아래 네 사례는 같은 문제를 반복해 설명하지 않고, 각각 다른 Local Y를 어떤 논리로 줄였는지 보여줍니다.

01

측정시스템 중심 Focused DMAIC

Vision 오판정

제품 규격을 완화하지 않고 검사기가 양품을 해석하는 방식을 바로잡았습니다.

문제 정의

  • Can Insert 이후 특정 회전방향의 제품이 반복적으로 NG 판정을 받았습니다.
  • 공정상 문제가 없는 양품도 Vision 인식 마진이 좁아 1종 불량으로 배출됐습니다.
  • 제품 형상 문제와 검사영역·Setting 문제를 분리해야 했습니다.

측정·기준

  • Press 두께는 공정 설계 마진 안에 있었습니다.
  • 극판 두께는 생산 과정에서 일정한 산포가 발생할 수밖에 없었습니다.
  • 기존 Vision은 두께오차를 0에 가깝게 두고 판정해 실제 공정 산포를 반영하지 못했습니다.
  • 회전방향별 정렬 위치와 NG 발생 방향을 비교했습니다.

원인 분석

4M확인한 후보확인 근거·판단
Man회전방향과 Setting 요령작업자가 방향별 정렬과 Setting 방법을 알지 못해 오판정이 이어지는지 확인했습니다.
Machine회전방향별 Vision 정렬위치제품 회전에 따라 정렬 위치가 조금씩 달라지는 현상을 확인했습니다.
Material극판 Press 두께 산포산포는 있었지만 공정 설계 마진 안이어서 우선 원인에서 제외했습니다.
Method양품 판정범위·불량 선별조건실제 두께 산포를 반영하지 못한 좁은 판정범위를 핵심 원인으로 남겼습니다.

조치·재시험

  • 회전방향별 정렬 위치를 다시 맞췄습니다.
  • 극판 두께 산포를 고려해 검사 마진을 넓혔습니다.
  • 검사영역과 양품 판정범위, 불량 선별조건을 다시 구성했습니다.
  • 내·외탭 Setting 값을 정리했습니다.
  • 방향별 판정 결과를 다시 비교해 실제 양품이 NG로 배출되지 않는지 확인했습니다.

결과·관리

  • 제품 검사규격 자체는 변경하지 않았습니다.
  • 확정한 Vision Setting 값을 관리항목으로 남겼습니다.
  • 제품의 실제 이상과 검사 오판정을 구분할 수 있게 됐습니다.
02

Focused DMAIC · 순차 원인 제거

저항용접과 Formation IR

Recipe보다 정렬·Head·전극·검사기준을 먼저 확인했습니다.

문제 정의

  • 저항용접 미용접이 Formation IR 불량의 주요 원인 중 하나로 나타났습니다.
  • 설비 상태와 전극관리, 검사기준과 용접조건이 한 결과에 함께 영향을 줄 수 있었습니다.

측정·기준

  • Head와 제품의 정렬 상태를 확인했습니다.
  • 전극 상태와 마모 산포를 확인했습니다.
  • 기존 검사기준이 실제 용접상태를 구분하는지 검토했습니다.
  • 공정 중 확인항목과 Formation IR 결과를 연결해 보았습니다.

원인 분석

4M확인한 후보확인 근거·판단
Man전극 교체·관리와 Setting 방법작업자별 관리방법이 전극 상태와 판정에 영향을 주는지 확인했습니다.
MachineHead 정렬·가압상태정렬과 가압을 먼저 안정화한 뒤 조건시험으로 넘어갔습니다.
MaterialTab 구조·소재변경Clad Tab의 내부저항 효과는 공정조건 개선과 분리했습니다.
Method검사기준·용접조건실제 용접상태를 구분하는지 확인한 뒤 조건을 한 항목씩 바꿨습니다.

조치·재시험

  • 정렬과 전극관리 기준을 먼저 안정화했습니다.
  • 용접조건은 한 항목씩 변경했습니다.
  • 변경 결과는 PQC, Nugget 크기와 파단형상, 인장력, Formation IR로 다시 확인했습니다.
  • Clad Tab 적용은 평균 내부저항에 영향을 준 별도 소재변경 효과로 분리했습니다.

결과·관리

  • 저항용접 관련 Loss를 약 4%에서 0.3% 수준으로 낮췄습니다.
  • 정렬·전극·검사·조건을 확인하는 순서를 관리항목으로 남겼습니다.
  • 세부 용접조건과 내부 관리값은 공개하지 않습니다.
03

분기형 Root Cause Validation

주액·누액·중량 산포

기계적 기밀구조와 Recipe 효과를 서로 다른 검증으로 관리했습니다.

문제 정의

  • 약 2,000 Cell 규모 Batch에서 주액 관련 Loss가 150~220 Cell 수준으로 발생했습니다.
  • 누액과 중량미달이 함께 나타났습니다.
  • 누액이 없는 제품에서도 중량미달이 발생해 두 현상을 하나의 원인으로 묶을 수 없었습니다.

측정·기준

  • Jig 위치별 Loss 패턴을 확인했습니다.
  • 누액 여부와 주액량을 별도 결과로 기록했습니다.
  • 위치별 중량 산포를 별도로 확인했습니다.

원인 분석

4M확인한 후보확인 근거·판단
ManJig 장착·정렬과 작업순서위치별 Loss가 작업방법과 연결되는지 확인했습니다.
Machine기밀·정렬·가압구조, Hopper·PumpO-ring 접촉과 Spring 상태, Hopper와 Pump 영향을 각각 확인했습니다.
MaterialO-ring과 주액 관련 소재변경구조·설비 영향과 섞이지 않도록 별도 변경요인으로 관리했습니다.
Method위치·압력·진공·함침 SequenceRecipe 효과를 기계적 기밀구조 조치와 다른 단계로 검증했습니다.

조치·재시험

  • 구조 관련 조치와 Recipe 변경을 같은 시험에서 섞지 않았습니다.
  • Jig 정렬과 기밀구조를 먼저 보완했습니다.
  • 위치·압력·진공·함침조건을 단계적으로 재시험했습니다.
  • 조치 후 누액, 주액량과 위치 산포를 각각 다시 확인했습니다.

결과·관리

  • 기계적 문제와 공정조건 문제를 분리해 안정화 조건을 정했습니다.
  • 구조개선 효과와 Recipe 안정화 효과를 서로 다른 검증단계로 관리했습니다.
  • 누액·주액량·위치 산포를 서로 다른 관리항목으로 남겼습니다.
04

품질 Acceptance Gate

후공정 녹·외관 판정

외관 흔적과 기능 위험을 나눠 허용·차단 기준을 정했습니다.

문제 정의

  • 변색·용접흔·Scratch를 모두 같은 불량으로 처리할 수 없었습니다.
  • 후공정에서는 녹 발생과 환경조건도 함께 확인해야 했습니다.
  • 외관 흔적과 기능·안전 위험을 분리할 판정기준이 필요했습니다.

확인 기준

  • 실제 녹 발생 여부를 확인했습니다.
  • 기능에 영향을 주는지 확인했습니다.
  • 내부 유입 우려와 고객 VOC 가능성을 구분했습니다.
  • 한도견본 시험으로 허용 가능한 외관 범위를 확인했습니다.

원인·위험 분류

4M확인한 후보확인 근거·판단
Man외관 판정·한도견본 해석작업자별 판정을 줄이도록 허용·차단 경계를 한도견본으로 맞췄습니다.
Machine용접·세정·공조조건과용접 흔적, 세정상태와 공조 Bypass 영향을 분리해 확인했습니다.
MaterialTubing 변색·표면손상기능 이상과 단순 외관 차이를 구분했습니다.
MethodpH·세정주기·Scratch 판정결론 전 시험은 보류하고 기능·VOC 위험이 확인된 항목만 차단했습니다.

Gate 판단

  • 녹과 기능 문제가 없는 외관 흔적만 허용 후보로 검토했습니다.
  • 내부 유입 우려가 있거나 고객 VOC로 이어질 수 있는 Scratch는 허용 대상에서 제외했습니다.
  • 통과조건을 한도견본으로 관리했습니다.

결과·관리

  • 허용·차단 경계를 현장 판정기준에 반영했습니다.
  • 세정수 온도와 Brush 교체기준, 공조 Bypass 조건처럼 확인된 항목만 관리기준에 반영했습니다.
  • 결론이 나지 않은 pH 환수주기 시험은 완료 성과에서 제외했습니다.

기타 공정 개선 원장

대표 사례와 중복되지 않는 공정은 현상 → 판단·조치 → 검증·남긴 기준 → 상태만 남겼습니다.
