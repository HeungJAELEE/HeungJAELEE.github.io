2170 양산 수율 안정화

MSA로 측정 오판정과 실제 공정불량을 나누고 Jig·Recipe·소모부품·검사조건을 조정한 2170 조립라인 안정화 사례

2026. 7. 31. · 5 · 마지막 검토 2026. 7. 31.

  • 2170
  • MSA
  • SOP

30초 요약

수율 숫자를 바로 개선하려 하지 않고, 먼저 판정 오류와 실제 공정불량을 나눠야 올바른 설비·공정 조치를 정할 수 있다고 판단했습니다.

양산 안정화 결과
기간·기준
금양 재직 기간 중 · 2024.05–2025.09
프로젝트 형태
회사 프로젝트 · 조립공정 리더

해결하려던 문제

초기 실질 양품수율이 약 40%였고 생산·품질·설비가 서로 다른 분모와 불량 기준을 보고 있어 원인과 우선순위를 합의하기 어려웠습니다.

내가 맡은 범위

  • 생산량·검사량·재검·폐기 기준과 불량명을 맞추고 부서별 개선 일정과 재시험 결과를 관리했습니다.
  • MSA 결과를 바탕으로 판정 오류와 실제 불량을 나눈 뒤 Jig 공차, Recipe, 소모부품, Vision·검사조건을 한 항목씩 확인했습니다.

확인된 결과·현재 단계

  • 측정 결과 · 팀 결과 확인 범위의 실질 양품수율 약 40%→98.7%
  • 확인된 산출물 · 개인 역할 확정 조건을 SOP·QCP·P-FMEA·검사기준과 교육자료에 반영

팀 경계

수율은 생산·품질·설비·개발이 함께 만든 팀 결과이며, 제 역할은 조립공정 리더로 기준·우선순위·재검증을 연결한 것입니다.

공개 범위: 회사 원자료와 고객 규격은 공개할 수 없어, 경력자료와 직접 수행한 업무를 기준으로 고객·설비 정보를 제거해 정리했습니다.

아래 순서는 당시 담당업무를 바탕으로 공개 가능한 범위에서 일반화한 작업 흐름입니다.

3분 사례

왜 중요했나

2170 조립라인의 초기 실질 양품수율은 약 40%였습니다. 이때 수율 숫자만 보고 설비 조건부터 바꾸면 판정 오류를 실제 불량으로 오해할 수 있습니다. 반대로 실제 공정불량을 검사 문제로 돌리면 같은 문제가 다음 생산에서도 반복됩니다. 개선보다 먼저 생산량, 검사량, 재검과 폐기의 범위를 맞춰 수율 분모를 하나로 통일해야 했습니다.

내가 맡은 범위

조립공정 리더로서 생산계획과 재공, 불량, 비가동 현황을 정리했습니다. 생산·품질·설비·개발 담당자가 같은 분모와 불량명으로 결과를 보도록 기준을 맞추고 MSA 검토와 공정 조건별 재시험 일정을 조율했습니다. 확인된 조건을 현장 표준에 반영하는 일까지 맡았습니다.

진행 흐름

수율 분모 통일 → MSA로 판정 오류와 실제 불량 분리 → Jig·Recipe·소모부품·검사조건 확인 → 한 조건씩 재시험 → SOP·QCP·P-FMEA 반영

핵심 판단과 검증

  • MSA 결과로 검사자의 판단 오류와 측정계 변동을 먼저 확인한 뒤, 실제 공정불량과 분리했습니다.
  • Jig 공차와 상태, Recipe, 소모부품 마모, 검사조건을 한 묶음으로 점검하되 시험에서는 한 번에 한 조건만 바꿨습니다.
  • 시험 대상과 검사방법, 판정기준을 고정했습니다. 같은 조건에서 반복 결과가 확인된 경우에만 현장 기준으로 채택했습니다.

결과와 표준화

경력자료에 기록된 팀 성과는 실질 양품수율 **약 40%에서 98.7%**입니다. 확인된 조건과 점검 항목은 SOP·QCP·P-FMEA, 검사기준과 작업자 교육자료에 반영했습니다. 표준화 이후에는 작업자나 교대조가 바뀌어도 같은 분모와 판정기준으로 수율을 볼 수 있었습니다.

다른 현장에 옮길 수 있는 원칙

수율이 낮을수록 곧바로 Recipe부터 손대기보다 집계 기준과 측정 신뢰성을 먼저 확인해야 합니다. 이후에는 설비·소모부품·검사조건을 분리하고 한 조건씩 재시험해야 원인과 개선 효과를 설명할 수 있습니다.

한계

98.7%는 해당 라인의 확인 기간과 집계기준에서 나온 경력 수치이며 공개 원시 데이터로 재계산한 보편 성능이 아닙니다. 회사 원본 도면·Recipe·품질자료와 고객 규격은 공개하지 않습니다.

링크와 근거

공개 링크

프로젝트 근거와 실제 사용 화면을 확인할 수 있는 공개 자료입니다.

별도 공개 GitHub·보고서 링크는 없습니다. 정량 결과는 경력자료 기준으로 설명합니다.

면접에서는 수율 분모를 맞춘 방식, MSA로 판정 오류를 분리한 기준, 조건별 재시험 순서와 표준서 반영 범위를 설명할 수 있습니다.

Problem

설비 데이터 노이즈와 실제 공정 편차가 섞여 원인 판단이 늦어지고, 권취 공정 비가동과 부품 수명 문제가 파일럿 수율을 반복적으로 흔들었습니다.

Goal

신호 품질, 설비 상태, 공정 조건과 품질 측정을 분리해 추적하고, 같은 조건을 작업 표준·QCP·P-FMEA·MSA에 고정하는 것입니다.

Success

확인 기간의 2170 실질 양품수율이 약 40%에서 98.7%로 안정화되고, 확정 조건이 SOP·QCP·P-FMEA·검사기준에 반영되면 완료로 판단했습니다.

범위와 경계

포함 범위

  • 2170 조립 Pilot Line의 설비 신호 품질과 공정 조건 분리
  • Jig 공차·Recipe·소모부품·검사조건과 불량의 공통 추적
  • IATF 16949 기반 자사표준, QCP, P-FMEA와 MSA 기준

제외·미검증 범위

  • 회사 원시 데이터, 설비 도면, Recipe와 고객 규격 공개
  • 모든 원통형 셀 라인에 동일 수치가 재현된다는 주장
  • 양산 장기 Cpk·OEE를 공개 Evidence 없이 추가하는 표현

구현·검증 기준

해야 할 일

  • 설비 signal quality와 실제 process value를 구분해 시간 순으로 추적한다.
  • 정지·Loss·불량을 설비, 공정, 소재, 작업 조건별로 분류한다.
  • 확정 조건과 검사 기준을 QCP·P-FMEA·작업표준에 반영한다.

품질·운영 기준

  • 측정 체계가 변하면 개선 전후 비교를 승인하지 않는다.
  • 단기 최고값보다 반복 Lot의 안정 구간을 우선한다.
  • 내부 원본과 공개 문구의 기밀·수치 경계를 유지한다.

왜 이렇게 구성했나

  1. 신호 노이즈와 공정 편차를 먼저 분리

    잘못된 신호를 공정 이상으로 해석하면 조건 조정이 오히려 변동을 키울 수 있기 때문입니다.

  2. 설비 상태와 공정 조건을 함께 확인

    Jig 공차와 부품 마모가 공정 조건의 효과처럼 보일 수 있어 물리 상태를 같은 시험표에서 확인했습니다.

  3. 개선 조건을 문서 Gate로 고정

    개인의 기억이 아니라 QCP·P-FMEA·MSA와 표준서가 다음 Lot의 재현 기준이 되어야 했습니다.
