    TECHNICAL CASE STUDY

    2170 조립라인 실질 양품수율 약 40%→98.7%

    MSA로 측정 오판정과 실제 공정불량을 나누고 Jig·Recipe·소모부품·검사조건을 조정한 2170 조립라인 안정화 사례

    2026. 7. 31. · 4 · 마지막 검토 2026. 7. 31.

    • 2170
    • Battery
    • Yield
    • MSA
    • SOP

    문제와 배경

    2170 조립라인의 초기 실질 양품수율은 약 40%였습니다. 생산량을 늘리기 전에 먼저 해야 할 일은 낮은 수율의 원인이 제품, 설비, 검사 중 어디에 있는지 나누는 것이었습니다. 판정 장비의 오차를 제품불량으로 집계하면 잘못된 공정조건을 고칠 수 있고, 반대로 실제 불량을 검사 문제로 돌리면 같은 문제가 다음 Lot에서 반복됩니다.

    그래서 수율 숫자 하나보다 생산량·검사량·불량유형·비가동·측정방법을 같은 기준으로 맞추는 일부터 시작했습니다.

    내가 맡은 일

    • 조립공정 리더로 생산계획, 재공, 불량과 비가동 현황을 정리했습니다.
    • 생산·품질·설비·개발 담당자가 같은 분모와 불량명으로 결과를 보도록 기준을 맞췄습니다.
    • MSA와 Gage R&R 결과를 품질 담당자와 검토하고 판정 오류와 실제 공정불량을 나눴습니다.
    • Jig 공차, 설비 Recipe, 소모부품 마모, Vision·검사조건의 담당자와 재시험 일정을 관리했습니다.
    • 확인된 조건을 SOP·QCP·P-FMEA·검사기준과 작업자 교육자료에 반영했습니다.

    확인하고 바꾼 내용

    확인 대상확인한 이유조치
    수율 분모와 불량명부서마다 다른 숫자를 보고 있지 않은지 확인생산량·검사량·재검·폐기 기준을 한 표로 정리
    측정시스템판정 오류를 공정불량으로 세고 있지 않은지 확인MSA·Gage R&R 검토 후 판정과 공정 원인을 분리
    Jig·정렬 상태공차와 마모가 제품 위치에 영향을 주는지 확인Jig 공차와 교체·점검 기준 보완
    Recipe·소모부품조건 변경과 마모 영향이 섞이지 않는지 확인한 번에 한 조건을 바꾸고 같은 검사기준으로 재시험
    Vision·검사조건검출 조건이 실제 CTQ와 맞는지 확인품질 기준과 일치하도록 판정조건 재확인

    개선 시험에서는 여러 조건을 동시에 바꾸지 않았습니다. 시험 대상, 검사방법과 판정기준을 고정한 뒤 한 조건씩 비교하고, 반복 결과가 맞을 때만 현장 조건에 반영했습니다.

    결과와 한계

    • 검증 범위의 실질 양품수율을 약 40%에서 98.7%까지 높였습니다.
    • 개선 결과를 현장 문서와 교육자료에 남겨 작업자와 교대조가 같은 기준으로 확인하도록 했습니다.
    • MES는 제가 직접 수정한 것이 아니라 관리항목과 Cell Tracking 요구사항을 정리해 담당 조직에 기술요청했습니다.

    98.7%는 해당 2170 조립라인의 확인 기간과 집계기준에서 나온 경력 수치입니다. 공개 원시 데이터로 제3자가 다시 계산한 값이나 모든 2170 라인에 적용되는 보편 성능은 아닙니다. 회사 도면, Recipe, 설비 주소, 고객 규격과 원시 품질자료도 공개하지 않습니다.

    공개 링크와 다음 보완

    공개 링크

    프로젝트 근거와 실제 사용 화면을 확인할 수 있는 공개 자료입니다.

    회사 도면·Recipe·원시 품질자료는 공개하지 않습니다. 공개 글에는 제가 맡은 범위, 확인 방법과 이력서로 설명 가능한 결과만 적었습니다.

    면접에서는 수율 분모, MSA로 판정 오류를 나눈 방법, 조건 변경 순서와 표준서 반영 과정을 설명할 수 있습니다. 외부 공개용 원시 데이터나 회사 문서를 새로 올릴 계획은 없습니다.

    측정 오판정과 실제 공정불량을 먼저 나눈 뒤 Jig·Recipe·소모부품·검사조건을 같은 기준으로 재시험한 현장 사례입니다.

    Problem

    설비 데이터 노이즈와 실제 공정 편차가 섞여 원인 판단이 늦어지고, 권취 공정 비가동과 부품 수명 문제가 파일럿 수율을 반복적으로 흔들었습니다.

    Goal

    신호 품질, 설비 상태, 공정 조건과 품질 측정을 분리해 추적하고, 같은 조건을 작업 표준·QCP·P-FMEA·MSA에 고정하는 것입니다.

    Success

    확인 기간의 2170 실질 양품수율이 약 40%에서 98.7%로 안정화되고, 확정 조건이 SOP·QCP·P-FMEA·검사기준에 반영되면 완료로 판단했습니다.

    범위와 경계

    포함 범위

    • 2170 조립 Pilot Line의 설비 신호 품질과 공정 조건 분리
    • Jig 공차·Recipe·소모부품·검사조건과 불량의 공통 추적
    • IATF 16949 기반 자사표준, QCP, P-FMEA와 MSA 기준

    제외·미검증 범위

    • 회사 원시 데이터, 설비 도면, Recipe와 고객 규격 공개
    • 모든 원통형 셀 라인에 동일 수치가 재현된다는 주장
    • 양산 장기 Cpk·OEE를 공개 Evidence 없이 추가하는 표현

    구현·검증 기준

    해야 할 일

    • 설비 signal quality와 실제 process value를 구분해 시간 순으로 추적한다.
    • 정지·Loss·불량을 설비, 공정, 소재, 작업 조건별로 분류한다.
    • 확정 조건과 검사 기준을 QCP·P-FMEA·작업표준에 반영한다.

    품질·운영 기준

    • 측정 체계가 변하면 개선 전후 비교를 승인하지 않는다.
    • 단기 최고값보다 반복 Lot의 안정 구간을 우선한다.
    • 내부 원본과 공개 문구의 기밀·수치 경계를 유지한다.

    왜 이렇게 구성했나

    1. 신호 노이즈와 공정 편차를 먼저 분리

      잘못된 신호를 공정 이상으로 해석하면 조건 조정이 오히려 변동을 키울 수 있기 때문입니다.

    2. 설비 상태와 공정 조건을 함께 확인

      Jig 공차와 부품 마모가 공정 조건의 효과처럼 보일 수 있어 물리 상태를 같은 시험표에서 확인했습니다.

    3. 개선 조건을 문서 Gate로 고정

      개인의 기억이 아니라 QCP·P-FMEA·MSA와 표준서가 다음 Lot의 재현 기준이 되어야 했습니다.
