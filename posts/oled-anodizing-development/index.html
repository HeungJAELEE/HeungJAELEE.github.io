    Case A. OLED Dry-Etch Upper Electrode 혼산 Anodizing

    1. 기존 공정 문제와 CTQ

    OLED 공정온도 상승 후 기존 혼산 피막에서 다음 이상이 동시 발생했습니다.

    • 고온 노출 후 Crack·외관 열화
    • Particle 증가와 Etch Rate 저하
    • 피막두께 대비 Hi-Pot 산포
    • 소형 Sample과 대면적 제품의 위치별 편차

    성공기준

    • 고객 요구두께의 열노출 후 Crack 억제
    • 동일 Sample의 두께·Hi-Pot 판정 일치
    • 100×100 mm 조건의 500×500 mm 재현
    • 고객 Qual·실제품 적용

    2. DMAIC 기반 공정 재설계

    단계핵심 업무판정·산출물
    Define사용온도 상승·Crack·Particle·내전압 CTQ 정의개발범위·성공기준 확립
    Measure불량 Run Sheet·Bath 이력·피막두께·열·Hi-Pot 기준선기존조건 성능 Map
    Analyze4M·전류분포·Racking·두께·후처리 영향 분리핵심 설계축 도출
    Improve전처리·Anodizing·두께·후처리 조건군 재설계후보 Recipe·Sample 선정
    Verify반복시편→100×100 mm→500×500 mm→고객 QualScale-up 타당성 입증
    ControlRun Sheet·변경점·공정표준·검사기준 개정제품 적용조건 이관

    3. 4M 원인판정과 측정 확인

    분석대상추정원인확인결과조치사항
    Man작업·분석·판정 Sequence 편차표준화 대상작업·검사 Sequence 고정
    MachineBath·전원·온도·Racking·대면적 전류분포Scale-up 핵심축위치별 전류·Racking 조건 재설정
    MaterialAl 소재·혼산 Bath·피막·후처리 재료설계 필수축소재·Bath 이력별 Sample 비교
    Method전처리·피막조건·두께·후처리·열시험핵심 개선축조건군 설계·확인실험

    측정·환경 확인

    • Measurement: 두께·Crack·외관·Hi-Pot 산포 · 승인 근거 · 동일 Sample 반복측정·판정기준 정렬
    • Environment: 고객 고온 사용조건·사내 대기 열시험 · 개발조건 분리 · 사용환경 CTQ·시험환경 별도 관리

    4. 조건개발과 대면적 Scale-up

    불량이력·기존조건 기준화
→ 피막조건·두께·후처리 Sample
→ 24시간 대기 열시험
→ 동일조건 최소 3회 반복
→ Crack·외관·Hi-Pot 판정
→ 100×100 mm Sample
→ 500×500 mm 대면적 Sample
→ 고객 Qual
→ 실제품 적용

    소형시험 통과조건을 실제품에 바로 적용하지 않고, 면적 증가에 따른 전류분포·Racking·위치별 피막산포를 대면적 Sample에서 재검증했습니다.

    대표 시험조건기존 조건개선 조건판정
    50 μm 열시험 비교약 260℃약 350℃고온 적용범위 확대
    50 μm Hi-Pot 비교약 2.4 kV약 2.7 kV내전압 방향 개선

    5. 위험항목 개정과 표준문서 전개

    시험에서 추가·개정한 위험항목관리 Control표준문서 반영
    고온 Crack·외관 열화두께별 열시험·Crack 판정시험계획·검사기준
    대면적 전류분포·위치산포Racking·위치별 피막측정Run Sheet·작업표준
    두께–Hi-Pot 판정 불일치동일 Sample 반복측정검사 Sequence·결과표
    소형조건의 Scale-up 미재현100×100→500×500 Gate변경점보고서·제품 적용기준

    6. 결과

    • 혼산 피막조건·두께·Racking·검사 Gate 재설계

    Case B. Display PECVD Susceptor 수산 Anodizing

    1. 고객 요구와 설계대안

    신규 고온 사용조건에 대응해 다음 설계축을 비교했습니다.

    설계축비교대안판정항목
    MaterialSusceptor 소재·수산 Bath·피막·후처리피막균일성·Crack
    MachineBath·전원·Racking Jig·대면적 전류분포위치별 두께·외관

    Measurement두께·육안·현미경내부 Screening·고객 Qual

    2. 내부 Screening과 고객 Qual

    3. 위험항목 개정과 문서 이관

    검증에서 도출한 위험항목관리 Control문서 반영
    Racking 위치별 피막산포위치별 두께·외관 판정Run Sheet·Racking 기준
