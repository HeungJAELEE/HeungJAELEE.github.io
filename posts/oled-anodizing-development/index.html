양산 적용

디스플레이 장비부품 고내열 Anodizing 공정개발

OLED Dry-Etch Upper Electrode의 혼산 피막 재설계와 Display PECVD Susceptor의 수산 고온 Qual

프로젝트 기간
2017.01–2017.06 혼산 피막개발 · 2018.07–2018.10 수산 고온 Qual
맥락
와이엠씨 기술연구소 재직 중 수행
담당 범위
불량이력·Sample 확인, 조건별 제작·열·내전압 평가, 100×100→500×500 확대시험, 고객 Qual과 표준문서 반영

프로젝트 핵심 요약

과제 정의
OLED 공정온도 상승으로 Upper Electrode 계열의 기존 혼산 피막에서 Crack·Particle이 나타났고, Susceptor 계열에는 별도의 고온 Qual 요구가 생겼습니다.
핵심 역할
Six Sigma GB의 문제해결 순서를 바탕으로 Sample 제작·열·내전압 평가, 4M+2E 원인분리, 크기 확대시험과 공정·검사기준 정리를 수행했습니다.
주요 결과
혼산 조건은 고객 Qual과 제품 적용 후 약 1년을 추가 확인했고, 수산 조건은 450℃ 반복 Screening과 고객 진공 열시험을 거쳐 약 1년간 적용됐습니다.

프로젝트 개요

YMC 기술연구소에서 수행한 두 Anodizing 개발과제를 한 페이지에 정리했습니다. 두 과제는 모두 디스플레이 장비부품의 고온 신뢰성을 다뤘지만, 시작점과 완료조건은 달랐습니다.

대학 4학년 때 취득한 Six Sigma Green Belt의 문제해결 순서를 현장에 사용했습니다. 다만 당시 업무는 Charter와 Tollgate를 운영한 공식 Six Sigma 과제가 아니었습니다. 현상과 측정값을 먼저 확인하고 4M·5 Why·Pareto와 비교시험으로 원인을 좁힌 뒤, 재시험과 표준문서로 마무리한 실무를 DMAIC 관점으로 정리했습니다.

01

DMAIC 관점의 양산조건 재설계

OLED Dry-Etch Upper Electrode용 혼산 Anodizing

OLED 공정온도 상승 이후 나타난 Crack·Particle·Etch Rate 문제를 소형 Sample에서 대면적 제품까지 단계적으로 확인했습니다.

왜 다시 개발했는가

OLED 공정온도가 높아지면서 기존 혼산 Anodizing 피막을 적용한 Upper Electrode 계열 부품에서 Etch Rate 저하, Particle과 Crack이 함께 확인됐습니다. 약액조건만 바로 바꾸지 않고 불량 Run Sheet, 성적서, 작업일, Sample 사양, 온·습도와 기존 Bath 이력을 먼저 확인했습니다.

완료조건은 다음 네 가지로 정했습니다.

  1. 고객 요구두께에서 열노출 후 Crack이 발생하지 않을 것
  2. 같은 Sample의 내전압이 피막두께별 판정기준을 만족할 것
  3. 100×100 mm 시험결과가 500×500 mm 대면적 Sample에서도 같은 방향으로 재현될 것
  4. 고객 Qual 후 실제 제품에 적용할 수 있을 것

4M+Measurement+Environment

원인축확인한 후보시험·판정처리
Man작업순서와 분석·검사방법 차이동일 Sample의 작업·판정순서를 맞춤핵심 기술원인보다는 표준화 항목으로 유지
MachineBath·전원·온도관리·Racking·후처리설비소형과 대면적 위치별 결과 비교면적 확대 시 확인해야 할 주요 후보
MaterialAl 소재, 혼산 Bath, 피막·후처리 재료소재·Bath 이력과 피막결과 비교핵심 설계축으로 유지
Method전처리, Anodizing 조건, 피막두께, 열시험조건별 Sample과 반복시험핵심 개선축으로 채택
Measurement두께, Crack, 외관, Hi-Pot같은 Sample을 3회 이상 반복 측정판정 신뢰성 확인
EnvironmentOLED 공정온도 상승, 대기 열시험, 온·습도실제 사용조건 변화와 작업환경을 분리공정온도 상승은 개발배경, 일반 습도는 단일 원인으로 확정하지 않음

실제 시험순서

불량이력·기존조건 확인
→ 변수별 시험편 제작
→ 고객 요구두께 40·45·50 μm 범위 비교
→ 대기조건 24시간 열시험
→ 동일조건 최소 3회 반복
→ Crack·외관·내전압 확인
→ 100×100 mm Sample
→ 500×500 mm 대면적 Sample
→ 고객 Qual
→ 실제 제품 적용

100×100과 500×500은 제작수량이 아니라 Sample의 가로·세로 크기입니다. 소형 시험편의 조건을 곧바로 실물에 적용하지 않고, 면적 증가에 따른 전류분포·Racking·위치별 편차를 다시 확인했습니다.

과거 시험자료에 남은 대표 50 μm 조건에서는 기존 피막 대비 약 260℃→350℃, 내전압 약 2.4 kV→2.7 kV 범위까지 비교했습니다. 이 값은 당시 대표조건의 비교결과이며 40·45·50 μm 전체 제품의 공통 Spec으로 사용하지 않습니다. 정확한 승압 Sequence와 내부 판정값도 공개하지 않습니다.

결과와 표준화

  • 고객 Qual 승인 후 실제 제품에 적용했습니다.
  • 프로젝트 완료 뒤 약 1년 동안 기존 조건 제품이 섞인 과도기와 개선조건의 안정화 상태를 추가 확인했습니다.
  • Run Sheet, 시험결과보고서, 변경점보고서, 공정표준서와 검사기준에 확인조건을 반영했습니다.
  • 피막 Recipe, Bath 조성, 고객 고유 Spec과 Part Number는 공개하지 않습니다.
02

요구조건·Sample Gate·고객 Qual

Display PECVD Susceptor용 수산 Anodizing

글로벌 장비사의 고온 요구조건을 내부 대기 Screening과 고객 진공 열시험으로 나눠 검증했습니다.

고객 요구와 설계제약

Display PECVD Chamber에서 Glass Substrate를 지지·가열하는 Susceptor 계열 부품에 더 높은 고온 신뢰성이 요구됐습니다. 협업기간 중 기존 Bath 농도를 임의로 바꾸기 어려웠기 때문에 피막조건·두께·Hybrid 방식과 Racking 위치를 설계대안으로 두었습니다.

혼산 과제처럼 양산불량을 개선하는 DMAIC 프로젝트로 포장하지 않고, 다음 Gate로 진행했습니다.

고온 요구조건 확인
→ 피막조건·두께·Racking 대안
→ 내부 대기 Screening
→ 통과조건으로 별도 고객 Sample 제작
→ 고객 진공 열시험 Qual
→ 실제 제품 적용

내부 Screening과 고객 Qual을 분리한 이유

판정육안·현미경 Crack 확인고객의 열시험과 종합 Qual
목적피막조건·두께 후보 선별실제 장비 사용조건의 적합성 확인

내부시험은 같은 Sample 3개를 대기조건 450℃×24시간으로 5회 반복했습니다. 각 Cycle 후 육안과 현미경으로 Crack을 확인했습니다. 내부 통과조건과 동일한 Spec으로 별도 Sample을 제작해 고객의 진공 열시험에 제출했습니다.

4M+Measurement+Environment

원인축확인한 후보판정
Man작업순서와 외관·현미경 판정반복시험의 관리항목으로 표준화
MachineBath·전원·Racking Jig·대면적 전류분배균일성에 영향을 주는 주요 후보
MaterialSusceptor 소재, 수산 Bath, 피막·후처리필수 설계축
Method피막조건·두께·Hybrid 방식·열 Cycle핵심 설계대안
Measurement두께·육안·현미경 Crack내부 Screening과 고객 Qual의 판정근거
Environment내부 대기시험과 고객 진공시험서로 다른 시험환경으로 분리해 기록

결과와 공개경계

  • 내부 반복시험을 통과한 조건으로 고객 Qual용 Sample을 제작했습니다.
  • 고객의 진공 열시험 Qual을 거쳐 실제 제품에 약 1년간 적용했습니다.
  • 복수 후보업체와 비교했다는 전달은 있었지만 평가조건과 타사의 결과를 직접 확인하지 않았으므로 유일 Pass라고 표현하지 않습니다.
  • 정확한 장비 Model, Recipe, 피막조건과 고객 Spec은 공개하지 않습니다.

분석장비는 Sample 준비부터 측정·판정까지 직접 운용했고, 외부분석이 필요할 때는 시험목적과 Sample 조건을 정해 의뢰한 뒤 사내 측정값과 제품결과를 비교했습니다. 장비를 많이 사용했다는 목록보다 각 장비 결과가 다음 공정조건과 고객 Qual 판정에 어떻게 쓰였는지를 기준으로 정리했습니다.

확인된 결과와 한계

두 프로젝트 모두 피막조건을 정하는 데서 끝내지 않고 Sample 확대, 반복시험, 고객 Qual과 실제 제품 적용까지 연결했습니다. 혼산은 기존 제품의 사용조건 변경에 대응한 양산 안정화 사례이고, 수산은 신규 고온 요구조건을 Sample Gate로 검증한 기술 Qual 사례입니다.

대표 50 μm 시험값은 조건을 붙여 본문에서만 사용했습니다. 불량률, 정확한 Recipe·Bath 분석값, 고객 Spec, 승인서와 경쟁사 비교결과는 공개 성과로 사용하지 않습니다.

연결된 Bath 관리 사례

피막조건 개발 이후 Bath 사용기간에 따른 성분소모와 제품결과를 연결한 작업은 혼산 Anodizing Bath 분석·보충기준 표준화에서 설명합니다.
