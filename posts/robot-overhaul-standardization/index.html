1. 프로젝트 배경 및 과제

YMC 신규사업 초기에는 대상 Robot의 Parts List, 분해·조립순서, Torque, Align, Encoder Zero와 검사기준이 정리돼 있지 않았습니다. 외관상 조립이 끝나더라도 다음과 같은 잠재 고장이 고객 Site에서 드러날 수 있는 구조였습니다.

  • Base·Body 조립 단차와 Align 불량에 따른 좌표오차·간섭·반복정밀도 저하
  • Encoder Zero 이탈과 구동부 조립편차에 따른 Home 복귀·Teaching 오류
  • Seal 손상·조립면 오염에 따른 진공 Leak·Particle·Outgassing
  • Bearing·Belt·Motor·Encoder 상태불량에 따른 부하 Cycle 진동·Alarm
  • 현장 설치·Teaching 좌표 불일치에 따른 이송오류와 Line Stop

단순히 부품을 교체하는 방식으로는 작업자별 편차와 잠재고장을 통제하기 어려웠습니다. 외부 기술전수와 정상 중고품·고장품·고객 반입품의 분해분석을 통해 기종별 구조와 고장형태를 정리하고, FMEA의 Failure Mode–영향–원인–예방 Control–검출 Control 순서로 Overhaul 공정을 설계했습니다.

Check Sheet는 작업 내용을 기록하는 행정양식이 아니라, FMEA에서 도출한 예방·검출 Control이 다음 공정으로 넘어가기 전에 빠짐없이 실행됐는지 확인하는 현장 Control Plan으로 사용했습니다.

예방 Control–검출 Control 이중화를 기본 원칙으로 적용했습니다. 조립 Sequence·Align 기준은 예방 Control, FARO 반복측정은 정도 검출 Control로 구성했습니다. Seal·세척기준은 예방 Control, Helium Leak는 비가시 누설 검출 Gate로 배치했습니다.

※ Environment: 진공·청정 Failure Mode에 한정 적용. 기타 Gate의 핵심 원인축에서 제외.

3. 핵심 Failure Mode별 실행

① 정렬 틀어짐·Encoder Zero·반복정밀도 불량

Failure Mode

  • Base·Body 조립 단차
  • Arm 체결·Torque 편차
  • Align 기준 위치 불일치
  • Encoder Zero Point 이탈

예방 Control

  • 정상품·고장품 분해과정에서 기종별 부품관계와 조립순서 확인
  • Part 규격·방향·조립위치를 Parts List와 분해·조립 Manual에 고정
  • Base → Body → Arm 순서로 체결·Align·Encoder Zero 작업순서 표준화
  • 작업자가 조립완료로 판단하기 전에 각 단계의 Check Point를 서명·기록

검출 Control

  • FARO를 이용해 Arm 끝단과 이동구간을 최소 15회 이상 반복측정
  • 반복위치, 직진도와 이동 중 흔들림을 같은 측정순서로 확인
  • Alarm·Home·Zero, Z·θ·Dual Arm 동작과 간섭을 반복 확인

정밀조립 Check Sheet에는 단순 완료표시가 아니라 부품확인 → 체결 → Align → Zero → FARO 결과 → 동작확인의 선후관계를 넣었습니다. 앞 단계의 상태가 맞지 않으면 다음 검사의 결과도 유효하지 않기 때문입니다.

② 진공 Leak·Particle·Outgassing

Failure Mode

  • Seal 손상 또는 규격불일치
  • 조립면 단차·이물·잔류물
  • 세척·건조 미흡
  • 진공에 맞지 않는 윤활재·수명부품 사용

예방 Control

  • Bearing·Belt·Motor·Encoder·Seal의 마모와 규격을 입고·분해 단계에서 확인
  • 교체부품과 Seal의 규격·상태·진공적합성을 Parts List와 교체기준에 반영
  • Part 세척·건조, 조립면 확인과 잔류물 관리순서 표준화

검출 Control

  • Base·Body 조립 후 Helium Leak를 필수 검사 Gate로 적용
  • Seal·조립면·연결부별 검사순서와 결과를 Leak Check Sheet에 기록
  • Leak 확인 후 Arm 조립과 최종 정도검사로 이동

진공누설은 외관검사만으로 판정하기 어렵습니다. 따라서 Seal 확인·세척·조립은 예방 Check, Helium Leak 결과는 출하판정을 위한 검출 Check로 분리했습니다.

③ 부하 구동·고객 Site Teaching 오류

Failure Mode

  • 무부하에서는 정상이나 End Effector 장착 후 진동·Alarm 발생
  • 이동구간 간섭 또는 반복 복귀오차
  • 고객 Site 설치기준·Teaching 좌표 불일치

예방 Control

  • 구동부품 상태, Belt 장력, Arm 간섭과 조립상태 사전 확인
  • 출하 전 동작 Program·Teaching 순서와 부하조건을 표준화
  • Site 설치·정렬·좌표 확인순서를 Setup Check List로 구성

검출 Control

  • End Effector 장착상태에서 부하 Cycle 50회 이상과 Dry Run 수행
  • 반복 복귀·Alarm·간섭·진동을 출하검사표에 기록
  • 고객 Site에서 설치·정렬·Teaching, 실제 동작과 초도 Sample Qual 확인

사내 검사와 Site 인수는 같은 목적이 아닙니다. 사내에서는 장비 자체의 기계·진공·구동상태를 확인하고, Site에서는 실제 Layout·좌표·제품동작에 맞는지를 최종 확인하도록 Check Sheet를 분리했습니다.

4. YMC 0→1 기술내재화와 본테크 반복 Overhaul 확장

YMC — 신규 기종 기술을 0에서 표준으로 전환

  • 3인 로봇조직에서 신규사업 실무를 총괄
  • 외부 기술전수 후 정상 중고품·고장품·고객 반입품을 분해해 Part 규격과 조립관계 확인
  • 기종별 Parts List, 분해·조립·작동·검사 Manual과 Run Sheet 작성
  • 입고·분해·정밀조립·Leak·FARO·Cycle·출하·Teaching Check Sheet 구축
  • 초도 Qual 완료 후 동일 Model 약 5대 출하

본테크 — 반복 Overhaul·작업자·현장 운영으로 확장

  • 반복 Overhaul에서 자주 발생하는 부품마모·정도 Setting·Leak·작업순서 문제를 FMEA 항목으로 재정리
  • 부품수명·교체기준, 작업자 OJT와 독립작업 평가를 본테크 운영환경에 맞게 적용
  • 국내외 고객 Site에서 설치·정렬·Teaching·Leak·반복정밀도·초도 Sample Qual 수행
  • 사내 Overhaul 결과와 고객 Site 인수결과를 같은 장비이력으로 연결해 운영부서에 이관

YMC에서 신규 기종의 기준을 만들고, 본테크에서 반복 작업과 현장 Setup까지 확장하면서 한 대를 고치는 기술을 여러 작업자가 같은 Sequence와 검사 Gate로 재현하는 제조·장비 표준으로 전환했습니다.

6. 최종 성과 및 표준화

  • 신규 기종의 고장형태를 FMEA 기반 Failure Mode·영향·원인축으로 분리
  • 각 Failure Mode를 예방 Control과 검출 Control로 나눠 작업순서와 검사 Gate 설계
  • Parts List, 입고·분해·조립·Leak·정도·Cycle·Site Setup Check Sheet 제정
  • FARO 최소 15회 반복측정과 End Effector 부하 Cycle 50회 이상을 출하검수에 적용
  • YMC 초도 Qual과 동일 Model 약 5대 출하
  • 본테크 반복 Overhaul, 작업자 OJT와 국내외 Site 설치·Teaching·초도 Qual로 확장
