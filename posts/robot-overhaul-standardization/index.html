진공로봇 Overhaul 작업표준화

구전 작업을 분해·조립·Align·Leak·반복정밀도·교육 흐름으로 정리

프로젝트 기간
2021.02–2022.03
맥락
본테크 로봇기술팀 재직 중 수행
담당 범위
분해·세척·부품교체·정밀조립·최종검사와 SOP·교육

현장 문제와 결과 요약

현장 문제
작업자 경험에 의존하던 분해·조립과 검사 순서 때문에 작업시간과 누락 항목이 달라졌습니다.
내가 맡은 일
부품교체와 정밀조립을 직접 수행하면서 Parts List, Torque, Align, Leak와 반복정밀도 기준을 문서화하고 교육했습니다.
확인한 결과
SOP·점검표를 현장에 적용했고, 같은 기간 팀 월 출하 실적은 1–2대에서 4–5대로 늘었습니다.

문제와 배경

진공로봇 Overhaul은 분해·세척·부품교체만으로 끝나지 않습니다. Arm 정렬, Encoder 원점, 진공 Leak와 반복정밀도가 기준 안에 들어와야 장비에 다시 투입할 수 있습니다. 당시에는 작업순서와 검사 노하우가 작업자 경험에 많이 의존해, 사람에 따라 조립시간과 확인항목이 달라지는 문제가 있었습니다.

내가 맡은 일

입고 → 분해 → 세척 → Bearing·Belt·Motor 교체 → 정밀조립 → Leak Test → Arm 조립 → Align → 반복정밀도 확인 → 출하 순서로 작업을 직접 수행했습니다. Torque Wrench로 체결하고, FARO로 위치와 정렬을 확인했으며, Encoder Zero를 설정하고 Teaching Pendant로 좌표를 확인했습니다. Helium Leak Test와 이상 소음·구동상태 확인도 이 과정에 포함했습니다.

Arm·Center·Base 단위로 분해·조립 순서를 나누고, Parts List와 체결순서, 검사방법, 이상 시 조치와 부품교체 기준을 SOP와 점검표로 정리했습니다. 문서 적용 뒤에는 작업자 교육과 초도 작업 확인을 함께 진행했습니다.

작업 편차를 확인한 4M 분석

Overhaul 작업 편차를 작업자 숙련도만의 문제로 보지 않았습니다. 4M으로 나누니 교육이 필요한 부분과 부품·장비·검사기준을 손봐야 할 부분이 구분됐습니다.

4M확인한 문제표준화한 내용
Man구전으로 배운 순서와 확인항목이 작업자마다 달랐음교육 순서, 작업 단계별 확인자와 초도 작업 확인
MachineBearing·Belt·Motor 마모, Arm 정렬, Encoder Zero, Leak와 이상 소음이 서로 다른 고장원인을 가짐부품상태, Align·Zero, Leak·반복정밀도 검사를 단계별로 분리
Material교체부품의 사양, Seal 상태, 세척 후 부품의 오염과 재사용 가능상태가 조립 결과에 영향을 줌Parts List, 교체기준과 세척·입고 상태 기록
Method분해·조립 순서, Torque, 검사 위치와 판정방법이 작업자 경험에 의존했음체결순서·Torque·검사방법·이상조치를 SOP와 점검표에 명시

이 구분으로 조립 문제와 검사 문제를 한꺼번에 고치지 않았습니다. 부품상태를 먼저 확인한 뒤 정렬과 원점을 맞추고, 마지막에 Leak와 반복정밀도로 조립 결과를 확인하는 순서를 고정했습니다.

DMAIC로 만든 작업표준

  1. Define — 작업자마다 다른 조립시간과 누락되는 검사항목을 줄이고, 출하 전 품질기준을 같은 순서로 확인하는 것을 목표로 정했습니다.
  2. Measure — 입고상태, Overhaul 기간, 부품교체, Torque, 7 mm·50 μm 검사기준, 15회 반복과 Leak 결과를 작업 단계별로 기록했습니다.
  3. Analyze — 편차를 4M으로 나눠 작업 숙련, 부품상태, 조립·정렬과 검사방법의 영향을 구분했습니다.
  4. Improve — Arm·Center·Base별 순서, Parts List, Torque, Align·Zero와 이상조치를 SOP·점검표로 정리하고 교육에 사용했습니다.
  5. Control — 작업기록과 최종검사표를 남기고 교육 뒤 초도 작업을 함께 확인해 같은 기준이 실제 작업에 적용되는지 점검했습니다.

확인하고 바꾼 내용

단계확인 항목정리한 내용
입고·분해외관, 구동상태, 부품 위치입고점검과 분해순서
세척·교체오염, Bearing·Belt·Motor 상태교체기준과 Parts List
조립체결순서, Torque, Arm 위치조립순서와 주의사항
정렬·원점Arm Align, Encoder Zero기준점과 확인방법
최종검사Leak, 반복정밀도, Teaching, 시운전검사순서·판정·이상조치

문서는 단순 작업설명서가 아니라, 다음 작업자가 같은 순서로 조립하고 같은 검사에서 이상을 찾을 수 있도록 구성했습니다.

반복정밀도에서 서로 다른 두 기준

검사에서는 최대 이동거리에서 End Effector 말단부의 상하 흔들림을 고객 기준 7 mm 이하로 확인했고, 최종 정지위치의 좌우 반복변동은 50 μm 이하 기준으로 확인했습니다. 반복검사는 15회 이상 진행했습니다. 두 값은 방향과 의미가 다르기 때문에 하나의 “정밀도” 숫자로 묶지 않고 점검표에서도 따로 기록했습니다. 로봇 한 대의 Overhaul 기간은 약 7~14일이었습니다.

결과와 현장 적용

  • 구전으로 전해지던 작업을 SOP·점검표와 교육자료로 정리했습니다.
  • 작성한 SOP·점검표를 실제 작업과 교육에 사용했습니다.
  • 같은 기간 팀의 월 출하 실적은 1–2대에서 4–5대로 늘었습니다.
  • 조립과 검사 항목을 한 흐름으로 묶어 작업자별 누락을 줄였습니다.
  • 해외 현지 고객사에서는 현장 Set-up과 Teaching, 재직 기간 중 수행한 초도 Sample Qual까지 진행했습니다.

월 출하 증가는 SOP 하나만의 결과가 아니라 작업자 숙련, 수주·자재 상황과 현장 운영이 함께 만든 팀 실적입니다. 제가 직접 맡은 성과는 조립·검사 순서를 문서로 정리하고 현장에 적용해 작업자 교육까지 이어간 부분입니다.
