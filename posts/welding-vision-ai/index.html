팀이 해결하려던 품질문제

용접부 외관검사에서 전체 Accuracy보다 실제 불량을 정상으로 통과시키는 미검출 위험을 먼저 봤습니다. 반대로 판정기준을 지나치게 낮추면 정상품 재검사가 늘어 생산흐름에 부담이 됩니다.

팀 전체 시스템

flowchart LR A["이미지·라벨 준비\nTEAM"] --> B["전처리·후보모델 학습\nSHARED·MY CORE"] --> C["점수·판정기준\nMY CORE"] C --> D["불량후보·수동확인\nTEAM"] --> E["오류 재검토\nSHARED"] E -.-> F["생산 적용검증\nFUTURE"]

팀은 이미지 입력부터 모델 결과와 수동확인 화면까지 시연했습니다. 저는 전체 기획과 모델링·평가, 미검출 우선 판정기준을 맡았습니다. 보고서는 공동 작성했고 발표는 팀장이 담당했습니다.

내가 직접 맡은 평가기준

판단항목확인한 이유사용방법
미검출실제 불량 통과위험Recall과 오류이미지를 먼저 확인
오검정상품 재검사·Cycle Time 부담Precision과 재검사량을 함께 비교
낮은 신뢰도모델 확률만으로 합격·불합격 확정 불가재촬영 또는 수동확인으로 전환
작업자와 모델 불일치자동판정의 오사용 방지사람이 원본이미지를 다시 확인

촬영조건이 다른 Sample에서 확인한 변화

공개 용접자료는 후보모델 학습에 사용했고, 별도 촬영 Sample은 조명·각도·표면반사 변화에서 오류가 달라지는지 확인하는 제한 자료로 사용했습니다. 별도 촬영 Sample은 독립 Test Set이나 생산성능 검증이 아닙니다. 전용 저장소·고정 평가셋·재현 실행환경이 공개되지 않아 데이터 수량과 최종 성능점수는 대표 결과에서 제외합니다.

팀 결과와 현재 단계

5인 팀은 촬영조건 차이에 따른 오류변화를 확인하고 미검출과 재검사 부담을 함께 비교하는 교육 PoC를 마쳤습니다. 생산 적용을 판단하려면 제품·Lot·촬영시점 단위의 독립 평가셋, 카메라조건 고정, 추론시간, Shadow Test와 모델·판정기준 변경이력이 더 필요합니다.
