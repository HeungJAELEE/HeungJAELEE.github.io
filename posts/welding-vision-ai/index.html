1. 문제 정의 및 Domain Gap

AI-Hub 공개 용접영상으로 학습한 ResNet Baseline을 직접 촬영한 용접실기품에 적용하자 Recall이 **15.84%**까지 하락했습니다. 모델 교체보다 먼저 공개자료와 촬영품의 데이터 분포 차이를 분석했습니다.

Error Analysis — 용접공정 노이즈 분류

제조검사에서는 Accuracy보다 실제 불량을 양품으로 보내는 FN·미검을 우선했습니다. FN과 FP 이미지를 용접공정 노이즈 기준으로 다시 분류했습니다.

4. Post-processing & Deployment

제조 품질비용 기반 Operating Point

제조 현장에서는 FP·과검에 따른 재확인 공수보다 FN·미검에 따른 품질 Escape의 영향이 더 큽니다. 수학적 최고 F1만 선택하지 않고 FN·FP 비용구조를 Threshold에 반영했습니다.

ThresholdFNFPRecallFPRF1판정 목적
0.40015100.0%16.3%93.1%미검 차단 Operating Point
0.4421298.0%13.0%93.4%중간 Trade-off
0.494496.0%4.3%96.0%F1 최고점

최종 운영점: 프로젝트 평가셋에서 FN 0건·Recall 100%를 기록한 Threshold 0.40 채택. 과검 15건은 작업자 재확인 대상으로 전환했습니다.

원본 이미지 좌표 스케일링

모델 입력 해상도의 결함좌표를 스마트폰 원본사진에 다시 매핑했습니다.

scale_x = 원본 가로 / 모델 입력 가로
scale_y = 원본 세로 / 모델 입력 세로

원본 x 좌표 = 모델 x 좌표 × scale_x
원본 y 좌표 = 모델 y 좌표 × scale_y
