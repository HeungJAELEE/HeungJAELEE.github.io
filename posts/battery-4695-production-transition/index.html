4695 조립설비 Auto Cycle 복구 및 제한 생산 전환

수동 운전에 의존하던 조립라인을 초기 SAT 기준으로 다시 확인하고, 공정별 4M+2E·Punch 재시험과 실제 Cell Run으로 생산 시작조건을 정리

프로젝트 핵심 요약

과제 정의
Start부터 종료까지 자동으로 이어지는 설비가 없고 정상 MES 이력도 남지 않아, 조립 전공정의 생산 시작조건을 초기 SAT 기준으로 다시 확인해야 했습니다.
핵심 역할
조립 전공정 시험방향과 판정기준을 정하고, 공정별 4M+2E·Punch 담당·기한·재시험을 운영했습니다.
주요 결과
100 Cell×2 Lot 재시험과 최종 50 Cell One-way Run으로 제한 생산 시작조건을 확인하고 작업표준·QCP·P-FMEA·Check List·MES 관리항목을 개정·제정했습니다.
복구·조건 재시험 100 Cell × 2 Lot
최종 One-way Run 50 Cell

생산 전환 배경

제품개발은 끝났지만 Start부터 종료까지 자동으로 이어지는 설비가 한 대도 없었습니다. 작업자는 각 유닛을 수동으로 움직였고, 정상 Cycle이 아니어서 MES 이력도 실제 공정상태를 설명하지 못했습니다. 부분수리만 반복하면 어느 설비가 생산 가능한 상태인지 판단하기 어려웠습니다.

조립 전공정을 초기 SAT 기준으로 다시 확인했습니다. 공정 목적과 안전조건, 제품감지, 동작순서, 품질측정과 생산이력을 같은 기준으로 맞춘 뒤 실제 Cell로 생산 시작 여부를 판단했습니다.

설비가 한 번 움직이는 것만으로 생산 가능하다고 판정하지 않았습니다. 자동운전, 실제 제품품질, 측정과 이력이 함께 맞는 상태를 생산 시작조건으로 정했습니다.

대표 사례 — Collector Laser Welding Auto Cycle 복구

01

재-SAT · 4M+2E · 실제 Cell 재시험

수동조작 설비를 Auto Cycle로 복구

Safety Interlock을 유지하면서 제품감지·공정순서·대기시간·Clamp·정렬·Speed를 다시 맞췄습니다.

현상과 성공 판정기준

원통형 J/R 무지부와 Collector 집전판을 Laser로 용접하는 설비였습니다. 설비가 제품을 자동 배출하지 못해 작업자가 투입부터 배출까지 각 유닛을 수동으로 조작하고 있었습니다.

성공 판정항목기준
안전Door·Laser·작업자 보호 Interlock 유지
감지최신 제품을 Sensor가 안정적으로 인식
동작공정 Sequence와 유닛 간 대기조건 정상화
기구Clamp·가압·정렬이 제품조건과 일치
배출공정 완료 후 자동 배출
품질실제 Cell 검사결과가 정한 기준 충족
이력정상 Cycle과 제품결과 기록 가능

재현·측정

  • 작업자가 수동으로 조작하던 순서와 반복 Error 위치를 공정단계별로 기록
  • 정상설비의 Sensor·Sequence·대기·Speed와 현재 설비 비교
  • 최신 제품의 형상·크기·반사율이 감지와 정렬에 미치는 영향 확인
  • 기존 MES 대신 실제 설비동작과 반제품·Cell 검사결과를 같은 시험기록으로 관리

Local 4M+2E 판단

원인축확인한 후보판정근거최종 판단
Man작업자별 수동조작·우회순서작업자 인터뷰와 실제 조작순서 비교설비복구 전 임시대응, 표준화 대상
MachineSensor, 대기시간, Clamp·가압·정렬, 유닛 Speed같은 단계에서 반복되는 Error와 정상설비 비교핵심 원인
Material제품형상·크기·반사율 변경SAT 조건과 최신 제품의 감지결과 비교감지·정렬에 영향
Method공정 Sequence·대기조건·시험순서수동운전과 정상 Auto Cycle 흐름 비교핵심 원인
MeasurementMES 이력·실제 동작·제품검사정상 Cycle 기록이 없어 별도 시험기록으로 대조재시험과 생산판정 근거
Environment주변 설치조건반복 Error와 직접 연관성이 낮음주요 원인으로 채택하지 않음

직접 조치·재시험

  • Sensor 감지위치와 조건을 최신 제품에 맞춰 조정
  • 기능상 필요하지 않은 공정 대기시간 축소
  • Clamp·가압·정렬 재설정
  • 공정 Sequence와 설비 간 Speed 정합성 확인
  • Door·Laser·작업자 보호 Interlock 유지
  • 약 2주 동안 초기 SAT 방식으로 기능·동작·제품조건 재시험
  • 100 Cell씩 2개 Lot, 총 약 200 Cell 확인
  • 최종 50 Cell One-way Run으로 제한 생산 시작 판정

Punch 관리와 승인

Punch List는 완료표시만 남기는 문서가 아니었습니다. 현상과 품질영향, 담당자, 조치기한, 수정내용, 재시험방법과 판정결과를 한 흐름으로 관리했습니다.

관리항목적용내용
현상·영향어느 공정에서 어떤 Error와 품질위험이 발생했는지 기록
담당·기한기술·보전·제조·품질 담당과 양산 시작 전 완료일 지정
조치Sensor·Sequence·Speed·정렬·측정기준 변경내용 기록
재시험같은 제품·동작·검사기준으로 조치 전후 비교
판정정상가동과 실제 Cell 시험을 모두 통과한 경우 반영

조건범위 검토에는 Taguchi 분석을 활용했고, 시험 중 이상이 발생하면 공정목적과 제품결과를 기준으로 다음 시험방향을 다시 정했습니다. 최종 결과는 기술·개발·품질·제조혁신 책임자가 검토했습니다.
