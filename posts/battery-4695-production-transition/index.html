왜 초기 SAT 수준으로 되돌렸는가

제품 개발은 끝났지만 Start부터 종료까지 Auto Cycle이 이어지는 설비가 없었습니다. 작업자가 유닛을 수동으로 움직이는 동안 정상 MES 이력도 남지 않아, 부분수리만으로는 생산준비 상태를 판단할 수 없었습니다. 그래서 전공정을 초기 SAT 기준으로 다시 확인하고, Laser Welding 설비를 대표 사례로 복구와 재시험 과정을 정리했습니다.

양산 전환 일정과 Gate

  1. 초기상태수동 생산Auto Cycle·Vision·MES 이력이 실제 생산상태와 맞지 않았습니다.
  2. 재-SAT기능·공정 재확인Sensor·Interlock·Sequence·Speed·정렬과 판정기준을 다시 확인했습니다.
  3. 복구대표설비 Auto CycleSafety Interlock은 유지하고 제품감지·공정순서·대기·정렬을 정상화했습니다.
  4. 재시험100 Cell×2 Lot조치항목을 Punch List로 관리하고 같은 기준으로 다시 시험했습니다.
  5. 판단최종 50 Cell제한 생산을 시작할 수 있는지 판단하는 자료로 사용했습니다.
  6. 표준화문서·MES 관리작업·검사·Punch·이력관리 기준을 개정·제정했습니다.

생산 시작 Gate는 Start부터 종료까지 Auto Cycle 유지 → Vision·검사 정상작동 → 측정·판정 신뢰성 → 생산이력 기록 → 정상공정을 벗어난 제품의 기술판정 순서로 확인했습니다.

대표 공정 복구

Laser Welding Auto Cycle 복구

Safety Interlock을 유지한 채 제품감지·공정순서·정렬·Speed를 다시 맞췄습니다.

최초 상태

  • 작업자가 각 유닛을 수동으로 움직였고 정상 MES 공정이력이 남지 않았습니다.
  • 자동흐름과 품질판정 기준을 초기 SAT 수준에서 다시 확인해야 했습니다.

유지한 안전조건

  • Door·Laser·작업자 보호와 관련된 Safety Interlock은 변경하지 않았습니다.
  • 제품감지와 공정순서를 확인하는 대기시간만 조정해 Tack Time 정체를 줄였습니다.

직접 조치와 협업

  • 기술팀·보전팀이 Sensor·Interlock·Sequence·Speed·정렬을 재검증했습니다.
  • 제조팀은 시험과 생산을 보조했습니다.

Issue 관리와 재시험

Punch List는 단순 완료목록이 아니라 현상·영향 → 담당·기한 → 조치 → 같은 기준의 재시험 → 종료판정으로 운영했습니다. Auto Cycle 복구 후 Lot당 100 Cell씩 2개 Lot, 총 200 Cell을 시험했고 마지막 50 Cell의 연속 결과를 제한 생산 시작 판단자료로 사용했습니다.
