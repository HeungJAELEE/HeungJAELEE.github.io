현장 표준화

혼산 Anodizing Bath 분석·보충기준 표준화

단일 적정값 대신 성분별 분석과 Batch Sample 피막결과를 연결해 한국·중국 현장 기준으로 정리

프로젝트 기간
2017.07–2018.06
맥락
와이엠씨 기술연구소 재직 중 수행
담당 범위
문제정의, Sampling·반복분석, 외부비교, 제품 Sample 평가, 한국·중국 적용과 교육

프로젝트 핵심 요약

과제 정의
기존 분석값은 정상인데 건욕 후 약 3개월부터 Etch Rate·Particle·피막품질 문제가 반복됐습니다.
핵심 역할
Sampling을 주 2회로 늘리고 성분별 Bath 분석, 외부기관 비교와 Batch Test Sample 평가를 연결해 한국·중국 적용기준을 정리했습니다.
주요 결과
분석 SOP, Log Sheet, 보충·교체 판단과 제품 Sample 확인기준을 대상 Bath와 중국 현장에 적용했습니다.

프로젝트 개요

항목내용
기간2017.07–2018.06
대상OLED 제조장비부품용 혼산 Anodizing Bath
최초 현상건욕 후 약 3개월부터 Etch Rate 저하, Particle, Crack·외관·내전압 이상이 증가
직접 역할문제정의, Sampling 주기 변경, Bath·제품 Sample 비교, 외부검토 지원, 현장 적용과 중국법인 교육
완료범위한국 적용 후 중국 현장 재검증, 분석 SOP·보충기준·Sample 관리기준 정리

혼산 피막조건을 개발한 뒤에도 Bath 사용기간이 길어지면 제품성능이 떨어졌습니다. 약액은 사용량만큼 보충하고 있었고 기존 분석표도 정상범위였지만, 현장 제품에서는 Etch Rate와 Particle 문제가 다시 나타났습니다.

문제는 약액이 줄어든 총량이 아니라 각 성분이 서로 다른 속도로 소모된다는 점이었습니다. 기존 방식은 하나의 중화적정값을 초기 조성비로 환산해 같은 비율로 보충했습니다. 시간이 지나면 분석표의 총값은 맞아 보여도 실제 조성비가 달라질 수 있었습니다.

기존 분석값이 정상인데 제품이 불량했던 이유

기존 방법은 전체 산도를 한 번 측정한 뒤 초기 배합비를 기준으로 각 성분의 보충량을 계산했습니다. 그러나 실제 생산에서는 성분마다 소비량과 반응속도가 달랐습니다. 한 항목의 부족분을 전체 비율로 환산하면, 시간이 지날수록 일부 성분은 과다하고 다른 성분은 부족한 Bath가 될 수 있었습니다.

그래서 다음 두 자료를 같은 시간축으로 붙였습니다.

  • Bath: 성분별 분석값, Free·Total Acid, 용존 Al, pH와 사용기간
  • 제품: Batch Test Sample의 피막두께, Crack, 내열·내전압, 내산·내식, 조도와 외관
  • 고객평가: Etch Rate와 Particle 결과

세부 성분명과 조성비는 공개범위에서 제외했습니다.

실제 확인순서

기존 분석 Log와 제품불량 이력 대조
→ Sampling 주기 주 1회에서 주 2회로 변경
→ 같은 시점의 Bath를 성분별로 반복분석
→ 외부기관 3곳과 분석결과 비교
→ 기존법과 개선법으로 보충한 조건별 Sample 제작
→ Batch Test Sample의 피막·내전압·외관 확인
→ 시범적용 후 다음 건욕 Cycle까지 추적
→ 분석 SOP·Log Sheet·보충기준 정리

각 측정은 반복성을 보기 위해 같은 시점에서 여러 번 확인했고, 전체 개발·안정화 기간 동안 약 50회 수준의 분석과 Sample 비교를 수행했습니다. 외부기관 결과는 자체 분석법을 대신하는 정답으로 사용하지 않고, 사내 결과의 방향과 재현성을 확인하는 검토자료로 사용했습니다.

4M+2E로 확인한 항목

구분확인한 내용판단

Machine성분별 분석에 필요한 장비와 기존 장비의 한계기존 단일 적정만으로는 조성변화를 충분히 설명하기 어려움
Material원료 Lot, Bath 누적성분과 현지 원료 차이한국·중국을 같은 기준으로 단순 복사하지 않고 재검증
Method초기 조성비 기준의 일괄 보충, Sampling·교체주기핵심 개선대상
Measurement기관별 장비차이, 3회 반복, 제품 피막과의 상관분석값 단독이 아니라 제품 Sample과 함께 판정
Environment현장온도와 한국·중국 조건차이색상 등 영향은 확인하되 단일 원인으로 확정하지 않음

중국 현장에서는 기준을 다시 확인했습니다

한국에서 만든 기준을 중국법인에 그대로 전달했을 때 같은 성능저하가 다시 나타났습니다. 약액 자체를 국내로 가져올 수 없어 현지에서 조건별 Sample을 제작하고, 현지 분석값과 본사 평가결과가 같은 방향인지 확인했습니다.

현지 원료와 제품이 달랐기 때문에 보충기준을 그대로 복사하지 않았습니다. 약 일주일 동안 현장 Sample을 제작·평가하고 분석 담당자에게 Sampling, 반복측정과 판정순서를 교육한 뒤 현지 기준에 반영했습니다.

남긴 기준과 문서

  • 약액 분석 SOP와 Sample 채취기준
  • 분석 Log Sheet와 반복측정 기준
  • 성분별 보충량 산정·확인순서
  • Bath 교체 판단기준과 월별 제품 Sample 확인기준
  • 시험결과보고서와 연구원·중국법인 분석담당자 교육자료

Bath를 더 오래 사용할 수 있는 가능성은 확인했지만, 교체주기 변경은 고객 VOC와 영업 판단 때문에 재직 중 운영기준으로 채택되지 않았습니다. 따라서 3개월→6개월을 실제 절감성과로 사용하지 않습니다. 오래된 자료의 한국·중국 불량률도 분모와 집계방법이 닫히지 않아 공개 결과에서 제외했습니다.

함께 읽을 사례

이 분석기준은 혼산 피막개발 이후의 Bath 유지관리 문제를 다룹니다. 피막조건과 고온 Scale-up은 디스플레이 장비부품 고내열 Anodizing 공정개발에서 확인할 수 있습니다.
