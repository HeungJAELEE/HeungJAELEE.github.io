Cell S/N 생산이력 추적 도구

문제 공정별 MES 기록은 있었지만 한 Cell의 전체 이력이 연결되지 않아 고객 요청 10개 Cell의 검색·대조·정리에 약 3일이 필요했습니다.

직접 담당 MES 조회기능 추가가 비용 문제로 진행되지 않은 뒤 데이터 연결항목을 정의하고 Power Query 취합과 Excel VBA 검색로직을 약 3주간 직접 만들었습니다.

결과·현재 단계 Cell당 검색 약 5–10초, 10개 Cell 검색 약 3분, 보고서 작성 포함 약 반나절로 운영했고 재직 당시 현장 적용 후 담당자에게 인계했습니다.
