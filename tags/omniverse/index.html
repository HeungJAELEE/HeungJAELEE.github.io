협동로봇 디지털 트윈과 온디바이스 비전 AI 설계

프로젝트를 한 문장으로 설명하면 INDY7 협동로봇 3대로 구성된 소형 자동차 조립 라인을 가상 환경에 표현하고, Raspberry Pi 5와 Hailo-10H에서 실행하는 YOLOv11 비전 모델의 판정 결과를 PLC·SCADA·MES 데이터 흐름과 연결해 본 디지털 트윈·온디바이스 AI PoC입니다. 이 프로젝트의 핵심은 3D 화면을 화려하게 만드는 것이 아닙니다. 물리 설비의 제어, AI 검사, 가상 모델, 생산 이력을 서로 분리하면서도 하나의 공정 이벤트로 추적할 수 있게 만드는 것이 목표였습니다. 구분 내용 프로젝트 성격 협동로봇 조립 공정의 디지털 트윈·비전 검사 PoC 물리 대상 INDY7 협동로봇 3대 조립 라인 에지 AI Raspberry Pi 5 + Hailo-10H, YOLOv11 기반 검사 모델 3종 제어·운영 MELSEC PLC, SCADA, MES 연동 흐름 가상화 NVIDIA Omniverse 기반 공정 상태 시각화·사전 검증 설계 기록된 모델 결과 F1 Score 100%, 95%, 100% F1 Score는 프로젝트 데이터에 기록된 평가 결과이며, 데이터셋 규모·분할 방식·현장 장기 운영 결과가 모두 공개된 것은 아닙니다. 따라서 이 글에서는 해당 수치를 특정 평가셋에서의 결과로만 설명하고, 양산 현장의 영구적인 정확도로 과장하지 않습니다.
