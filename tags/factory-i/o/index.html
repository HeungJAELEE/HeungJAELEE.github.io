기가프레스 공장 DX 전환 시나리오: 현장 신호부터 가상 검증까지

프로젝트 자료 구현 배경과 검증 시나리오를 확인할 수 있는 공개 자료입니다. GitHub 프로젝트 목록 github.com/HeungJAELEE 기가프레스 관련 보고서 canva.com/design/DAHINy4ipdM 기가프레스 전용 공개 소스 저장소는 아직 분리되어 있지 않아 GitHub 프로젝트 목록을 연결했습니다. 다른 프로젝트의 저장소를 이 프로젝트의 소스로 오표기하지 않았습니다. 프로젝트를 한 문장으로 설명하면 현장 센서 신호를 곧바로 상위 시스템에 연결하는 대신, 에지 수집·PLC 제어·SCADA 가시화·Factory I/O 사전 검증의 네 계층으로 분리해 설비 변경의 영향을 먼저 확인할 수 있도록 구성한 제조 DX 시나리오입니다. 이 글에서 말하는 기가프레스는 대형 프레스 공장을 이해하기 위한 공정 맥락입니다. 실제 양산 기가프레스 전체를 구축했다는 의미가 아니며, 하드웨어 사양과 안전 회로가 확정되지 않은 부분은 설계 또는 PoC(개념 검증) 범위로 구분했습니다.
