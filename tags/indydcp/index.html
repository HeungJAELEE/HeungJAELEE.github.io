Indy7 로봇 Digital Twin 구현 프로젝트

문제 PC와 티치펜던트가 작업 데이터를 주고받을 때 JSON 참조를 보존하고, 로봇 명령과 상태 확인 경로를 한 흐름으로 정리해야 했습니다.

직접 담당 전체 프로젝트를 기획하고 로봇 제어·통합 구조 설계와 시스템 연동을 중심으로 Conty JSON, PC-HMI, Robot Controller, MQTT·DB, 읽기 전용 Web Twin을 구현했습니다.

결과·현재 단계 팀은 자동차 조립 시나리오와 Indy7 실물 시연을 연결했고, 개인 구현은 공개 저장소에서 명령·상태 경로와 읽기 전용 Web Twin으로 확인됩니다.
