1. Problem definition and domain gap

A ResNet baseline trained on AI-Hub weld images fell to 15.84% recall on directly captured practical weld specimens. Architecture replacement was deferred until the distribution gap between public data and captured images was analyzed.

DataScaleUseMain characteristics
AI-Hub weld images30,000 undercut and 30,000 overlap imagesBaseline and candidate trainingEnlarged weld regions with relatively consistent lighting and background
Directly captured specimensAbout 155–198 images by experiment stageField evaluationSoot, spatter, oxidation, metal reflection, angle, and background variation
Augmented imagesGenerated in the training pipelineCapture robustnessBrightness, lens flare, noise, JPEG, crop, and rotation

Error analysis — weld-process noise

False negatives were reviewed first because they represent missed defects. FN and FP images were regrouped by weld-process and capture noise.

Error signalProcess or capture causeModel impactAction direction
Soot and fume tracesHeat effect and surface contaminationLower defect-boundary contrastBrightness and contrast augmentation
Spatter and oxidationAdditional local patterns around the beadHigher false positivesCombine local texture and global shape
Metal reflectionLighting angle and curved surfaceMissing region or false highlightLens flare and brightness variation
Angle and distanceSmartphone placement variationROI shift and shape distortionCrop, rotation, and scale augmentation
Compression and sensor noiseMobile capture and transferLoss of small-defect textureGaussian noise and JPEG degradation

4. Post-processing and deployment

Manufacturing-quality operating point

False positives create reinspection work, while false negatives create quality-escape risk. The threshold was therefore selected by error cost rather than peak F1 alone.

ThresholdFNFPRecallFPRF1Decision purpose
0.40015100.0%16.3%93.1%Missed-defect-priority operating point
0.4421298.0%13.0%93.4%Intermediate trade-off
0.494496.0%4.3%96.0%Peak F1

Selected operating point: threshold 0.40, with zero FN and 100% recall on the project evaluation set. The 15 false positives were routed to operator reinspection.

Coordinate scaling to the source image

Defect coordinates from the resized model input were mapped back to the smartphone source image.

scale_x = source width / model-input width
scale_y = source height / model-input height

source x = model x × scale_x
source y = model y × scale_y
