Project background and vision

Manufacturing, semiconductor, and battery documents accumulate with different terms, folders, and links. When a similar issue returns, engineers must find not only one source file but also its parent concepts and related documents. After retrieval, root-cause reports, process specifications, and action plans still require repeated restructuring.

HeungTology connects the following workflow while retaining the Markdown knowledge source.

Distributed documents and metadata
→ Graphfy relationship visualization
→ incremental indexing of changes
→ natural-language retrieval and reranking
→ Gemma 12B engineering draft
→ engineer review and revision
→ revised knowledge reindexed

The public repository owns the Markdown/YAML, ChromaDB, BGE-M3, and reranker retrieval core. The additional runtime evidence consists of a local Graphfy relationship graph and three Markdown documents generated through a Gemma 12B Agent.

Incremental sync

Discover Markdown
→ filter excluded folders
→ compare modification time with checkpoint
→ select new and changed files
→ parse frontmatter and body
→ document-level ChromaDB upsert
→ update checkpoint

Only changed files are embedded instead of rebuilding the entire corpus. This turns ongoing manufacturing-document revisions into a repeatable synchronization procedure.

Search mode returns source candidates for review. Agent mode packages selected candidates and neighboring graph nodes into context for document drafting.
