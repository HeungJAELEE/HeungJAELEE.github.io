현장 표준화

혼산 Anodizing Bath 성분분석·보충기준 재설계

문제 적정값은 정상인데 건욕 경과 후 제품 피막성능이 저하돼 단일 분석값과 실제 제품결과의 불일치를 규명해야 했습니다.

직접 담당 Sampling을 주 2회로 높이고 3회 반복, 외부기관 3곳, 약 50회 Bath·제품 Sample 비교와 중국 현지 재검증을 수행했습니다.

결과·현재 단계 성분별 분석·보충·제품 Sample·Bath 교체판정 기준을 SOP·Log·교육으로 표준화했습니다.

실패 사례

Diffuser 초음파 박리 Scale-up 실패분석 및 R&D Stop Gate

문제 초기 약액+초음파 박리조건이 배기 인프라 미구축으로 Scale-up에서 물+초음파로 바뀌며 Erosion·Particle·재사용성 문제가 발생했습니다.

직접 담당 Lab·실물시험과 조도·현미경·SEM–EDS·Particle 분석으로 공정조건 변화와 고정 진동자 구조의 손상기전을 규명했습니다.

결과·현재 단계 Scale-up을 중단하고 기존공정으로 회귀했으며 상대이동·표면손상·재사용·EHS 필수 Gate를 제정했습니다.

상세 사례
기술 Qual 완료

글로벌 디스플레이 장비사 CVD·PECVD 부품 공정 재구성 및 기술 Qual 획득

문제 기존 공정·검사조건과 글로벌 장비사의 제품군별 Spec·Hi-Pot 판정기준이 연결되지 않았습니다.

직접 담당 영문 Spec을 Process Flow·Run Sheet로 전환하고 공정별 4M+Measurement와 Hi-Pot Correlation을 주도했습니다.

결과·현재 단계 7회 반복측정과 3회 재시험으로 기술실사 지적 1건을 Closure하고 기술 Qual·약 1년 후속 납품으로 연결했습니다.

상세 사례
양산 적용

디스플레이 장비부품 고내열 Anodizing 공정개발·Qual

문제 OLED 공정온도 상승과 PECVD 신규 고온 요구로 기존 피막의 Crack·Particle·Hi-Pot·대면적 균일성을 다시 설계해야 했습니다.

직접 담당 혼산은 DMAIC·4M·100×100→500×500 mm Scale-up, 수산은 450℃×24시간×5 Cycle Screening과 고객 진공 Qual을 직접 수행했습니다.

결과·현재 단계 두 피막 모두 고객 Qual과 실제품 적용으로 연결하고 Run Sheet·공정표준·검사기준을 개정했습니다.
