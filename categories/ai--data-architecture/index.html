HeungTology: 제조 지식을 연결하는 Neo4j 온톨로지와 Graph-RAG 설계 PoC

제조 현장의 지식은 작업표준서, 설비 매뉴얼, 품질 문서, 불량 분석 보고서와 엔지니어의 경험 속에 흩어져 있습니다. 검색창에 키워드를 입력하면 관련 문서를 찾을 수는 있지만, “어떤 공정 조건이 어떤 불량과 연결되고, 과거에는 어떤 조치로 해결했는가?”처럼 관계를 따라가야 하는 질문에는 답하기 어렵습니다. HeungTology는 이 문제를 해결하기 위해 제조 도메인 지식을 노드와 관계로 구조화하고, Neo4j 기반 지식 그래프를 Graph-RAG 검색 흐름과 연결하는 방법을 설계한 아키텍처·PoC 프로젝트입니다. 이 프로젝트는 엔터프라이즈 시스템을 양산 배포하거나 전체 사내 지식을 변환 완료한 사례가 아닙니다. 그래프 데이터 모델, 적재 원칙, 탐색 흐름과 LLM 연결 가능성을 검토한 설계 실증에 범위를 둡니다.

resumOpenAI: 경력 사실을 구조화하는 맞춤형 이력서 생성 PoC

프로젝트 한눈에 보기 resumOpenAI는 사용자가 입력한 경력·교육·프로젝트 정보를 직무에 맞는 이력서 초안으로 재구성하는 Flask·React·OpenAI 기반 LLM 애플리케이션 프로토타입이다. 이 프로젝트에서 중요하게 본 것은 문장을 화려하게 만드는 기능이 아니라, 원본 경력 사실을 잃지 않으면서 필요한 정보만 모델에 전달하고 생성 결과를 다시 검증할 수 있는 흐름이었다. 이 글은 프로토타입의 설계와 구현 관점을 설명한다. 별도의 학습 데이터셋, 학습 로그, 평가 결과로 확인되지 않은 fine-tuning 완료나 모델 성능 향상을 성과로 주장하지 않는다. 현재 단계에서는 프롬프트 규칙, 구조화 출력, 후처리 검증을 우선 적용하는 것이 합리적이라고 판단했다.
